# HTML 발표 덱과 스크립트 협업 조사

## 조사 목표

수집된 발표 디자인/프레임워크 레퍼런스를 활용해 PPT처럼 발표할 수 있는 HTML 덱을 만들고, 발표 스크립트 에이전트가 슬라이드 구조와 발표자 노트를 함께 넘기는 방식을 정했다.

## 확인한 근거

- reveal.js는 HTML 발표 프레임워크이며 speaker notes와 speaker view를 제공한다.
- reveal.js Markdown 기능은 notes 구분자를 통해 슬라이드와 발표자 노트를 함께 작성할 수 있게 한다.
- Slidev는 발표자 모드와 notes 편집 흐름을 제공한다.
- Marp는 Markdown을 HTML, PDF, PowerPoint로 변환하는 발표 생태계를 제공한다.
- HTML 발표는 키보드 이동이 기본 발표 경험이므로 키보드 조작과 접근성을 구조에 포함해야 한다.

## 설계 반영

- `deck-spec`에 `script_beat`와 `speaker_notes`를 넣어 발표 스크립트 에이전트와 HTML 렌더러의 협업 계약으로 삼았다.
- 생성 HTML은 16:9 슬라이드, 키보드 이동, 발표자 노트 패널, 진행률, 인쇄 모드를 포함한다.
- 원격 이미지와 외부 스크립트 없이 로컬 CSS와 스크립트만 사용한다.
- 디자인은 레퍼런스의 구조적 패턴을 참고하지만 원본 템플릿을 복제하지 않는다.

## 한계

- 현재 덱 렌더러는 자체 HTML 발표 엔진이며 reveal.js/Slidev/Marp를 설치하지 않았다.
- 실제 발표 주제별 고급 디자인은 deck spec과 theme 확장을 통해 반복 개선해야 한다.

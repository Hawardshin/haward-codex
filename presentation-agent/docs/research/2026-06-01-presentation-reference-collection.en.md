# Presentation Reference Collection Research

## Goal

Create an initial source bundle so the presentation agent can research beautiful PPT/HTML design, templates, reusable assets, presentation theory, and AI slide generation/evaluation before producing decks.

## Source Bundles Checked

- HTML presentation frameworks: reveal.js, Slidev, Marp, impress.js, Spectacle, WebSlides, Shower, remark, Bespoke.js, mdx-deck, DeckDeckGo.
- PPT/template galleries: Microsoft Create, Google Slides, Canva, Slidesgo, SlidesCarnival, Pitch, Figma Slides, Prezi, Beautiful.ai, Visme, Genially, Tome, Gamma, PitchDeck.com, Slidebean, SlidesMania, Envato Elements.
- Design galleries: Behance, Dribbble, Speaker Deck, SlideShare.
- Asset libraries: Unsplash, Pexels, Pixabay, Google Fonts, Lucide, Heroicons, Material Symbols, Tabler Icons, Phosphor Icons, Font Awesome Free, Noun Project, unDraw, OpenMoji, LottieFiles, Storyset.
- Presentation theory and practice: Duarte, TEDx Speaker Guide, Presentation Zen, Sequoia, Y Combinator.
- AI presentation research and conversion candidates: SlideBot, SlideAudit, PPTArena, PPTX2HTML, pptx-to-html5.

## Judgment

- Since final outputs may be HTML, prioritize `native_html` frameworks.
- Many PPT/PPTX templates have license or account conditions, so cataloging plus HTML reconstruction plans are safer than bulk file storage.
- Likes and views from design galleries are visual discovery signals only.
- Photos, icons, and fonts require source-specific terms review before local raw storage.

## Next Research Iterations

- Split out only template-gallery candidates where free PPTX download and local conversion are explicitly allowed.
- Collect sample decks per HTML framework and create purpose-specific base templates.
- Create a separate flow-pattern dataset for the presentation script agent.
- If high-fidelity PPTX visual conversion becomes necessary, compare LibreOffice, browser rendering, and open-source converters by security, license, and output quality.

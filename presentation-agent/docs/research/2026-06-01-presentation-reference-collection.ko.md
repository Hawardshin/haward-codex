# 발표 레퍼런스 수집 조사

## 조사 목표

발표 에이전트가 발표 자료를 만들기 전에 예쁜 PPT/HTML 디자인, 발표 템플릿, 재사용 가능한 에셋, 발표 흐름 이론, AI 발표 생성/평가 연구를 폭넓게 탐색할 수 있도록 초기 소스 묶음을 만들었다.

## 확인한 출처 묶음

- HTML 발표 프레임워크: reveal.js, Slidev, Marp, impress.js, Spectacle, WebSlides, Shower, remark, Bespoke.js, mdx-deck, DeckDeckGo.
- PPT/템플릿 갤러리: Microsoft Create, Google Slides, Canva, Slidesgo, SlidesCarnival, Pitch, Figma Slides, Prezi, Beautiful.ai, Visme, Genially, Tome, Gamma, PitchDeck.com, Slidebean, SlidesMania, Envato Elements.
- 디자인 갤러리: Behance, Dribbble, Speaker Deck, SlideShare.
- 에셋 라이브러리: Unsplash, Pexels, Pixabay, Google Fonts, Lucide, Heroicons, Material Symbols, Tabler Icons, Phosphor Icons, Font Awesome Free, Noun Project, unDraw, OpenMoji, LottieFiles, Storyset.
- 발표 이론/실무: Duarte, TEDx Speaker Guide, Presentation Zen, Sequoia, Y Combinator.
- AI 발표 연구/변환 후보: SlideBot, SlideAudit, PPTArena, PPTX2HTML, pptx-to-html5.

## 판단

- 최종 산출물을 HTML로 만들 가능성이 크므로 `native_html` 프레임워크를 우선 수집한다.
- PPT/PPTX 템플릿은 많지만 대부분 라이선스와 계정 조건이 있으므로 원본 저장보다 카탈로그와 HTML 재구성 계획이 안전하다.
- 디자인 갤러리의 좋아요/조회수는 시각적 영감 후보를 고르는 신호로만 사용한다.
- 사진/아이콘/폰트는 출처별 이용 조건이 다르므로 카탈로그에 저장하되, 실제 원본 저장은 개별 라이선스 확인 후 진행한다.

## 다음 반복 조사 방향

- 각 템플릿 갤러리에서 실제로 다운로드와 로컬 변환이 허용되는 무료 PPTX 후보만 별도 리스트로 분리한다.
- HTML 프레임워크별 샘플 덱을 수집하고, 발표 목적별 기본 템플릿을 만든다.
- 발표 스크립트 에이전트가 쓸 수 있도록 좋은 발표의 흐름 패턴을 별도 데이터셋으로 만든다.
- 고품질 PPTX 시각 변환이 필요하면 LibreOffice, 브라우저 렌더링, 오픈소스 변환기 후보를 보안/라이선스/출력 품질 기준으로 비교한다.

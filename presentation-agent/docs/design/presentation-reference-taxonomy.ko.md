# 발표 레퍼런스 분류

## 출처 유형

- `html_framework`: HTML 발표를 직접 만들 수 있는 프레임워크. 예: reveal.js, Slidev, Marp.
- `template_gallery`: PPT, Google Slides, Figma, 웹 기반 발표 템플릿 갤러리.
- `design_gallery`: Behance, Dribbble, Speaker Deck처럼 시각 영감과 실제 발표 사례를 찾는 곳.
- `asset_library`: 이미지, 아이콘, 폰트, 일러스트, 애니메이션 등 발표 제작 자산.
- `presentation_theory`: 발표 구조, 스토리텔링, 전달 방식에 대한 가이드와 실무 지식.
- `ai_presentation_tool`: AI가 조사, 구조화, 디자인 적용, PPTX export/import를 지원하는 발표 생성 도구.
- `ai_presentation_research`: AI 발표 생성, 평가, 편집 벤치마크 논문.
- `conversion_tool_reference`: PPTX를 HTML 또는 중간 포맷으로 바꾸는 도구 후보.
- `open_source_reference`: HTML/PPT/slide template 구현 아이디어를 얻을 수 있는 오픈소스 저장소나 discovery seed.
- `official_docs`: PowerPoint 개인 템플릿 사용법처럼 workflow 근거가 되는 공식 문서.

## 품질 신호

- `official`: 공식 문서, 공식 갤러리, 공식 저장소.
- `open_source`: 소스와 라이선스를 검토할 수 있음.
- `curated`: 사람이 선별한 갤러리 또는 템플릿 모음.
- `popular`: 널리 사용되거나 검색/커뮤니티 신호가 큼.
- `designer_signal`: 디자이너 포트폴리오, 좋아요, 조회수, 큐레이션 등 시각 품질 발견 신호.
- `practitioner_signal`: 현업 발표/피치/컨설팅 경험에서 나온 실무 신호.
- `research_signal`: 논문, 벤치마크, 데이터셋 등 검증 가능한 연구 신호.
- `workflow_reference`: 생성 순서, 업로드/import/export, 템플릿 적용 같은 작업 흐름을 참고할 수 있음.
- `korean_user_relevance`: 한국 사용자가 접근하기 쉽거나 한국어 기반 작업에 특히 유용함.

## HTML 변환 방식

- `native_html`: HTML을 직접 산출하거나 웹 프레임워크로 렌더링 가능.
- `pptx_requires_conversion`: PPTX 원본이 있을 때 변환 도구나 수동 재구성이 필요.
- `manual_rebuild_recommended`: 원본 포맷 또는 사용권 때문에 HTML로 직접 재구성하는 편이 안전.
- `reference_only`: 디자인/이론 참고만 하고 원본 변환 대상이 아님.
- `asset_reference`: 개별 에셋을 HTML/PPT 제작에 사용할 수 있는지 검토하는 대상.

## 일관성 있는 템플릿 기준

- 색상: primary, secondary, accent, neutral 역할을 고정한다.
- 타이포그래피: display, title, body, caption, number 역할을 고정한다.
- 그리드와 여백: 16:9 slide canvas 안에서 safe area, column, baseline rhythm을 고정한다.
- 레이아웃 archetype: hero, section divider, problem-solution, comparison, process, evidence, quote, closing처럼 재사용 가능한 family로 제한한다.
- 컴포넌트: callout, metric, timeline, logo row, quote, chart frame, source note를 같은 스타일 규칙으로 반복한다.

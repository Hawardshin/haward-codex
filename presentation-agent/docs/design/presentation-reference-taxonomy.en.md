# Presentation Reference Taxonomy

## Source Types

- `html_framework`: frameworks that can produce HTML presentations directly, such as reveal.js, Slidev, and Marp.
- `template_gallery`: PPT, Google Slides, Figma, or web-based presentation template galleries.
- `design_gallery`: sources for visual inspiration and real-world decks, such as Behance, Dribbble, and Speaker Deck.
- `asset_library`: images, icons, fonts, illustrations, animations, and other production assets.
- `presentation_theory`: guides and practitioner knowledge about presentation structure, storytelling, and delivery.
- `ai_presentation_research`: papers and benchmarks for AI slide generation, editing, and evaluation.
- `conversion_tool_reference`: candidate tools for converting PPTX to HTML or intermediate formats.

## Quality Signals

- `official`: official docs, galleries, or repositories.
- `open_source`: source and license can be reviewed.
- `curated`: human-curated gallery or template set.
- `popular`: broad usage or visible search/community signal.
- `designer_signal`: portfolio, likes, views, or curation that helps discover visual quality.
- `practitioner_signal`: field experience from presentation, pitch, or consulting practice.
- `research_signal`: papers, benchmarks, or datasets.

## HTML Conversion Paths

- `native_html`: produces HTML directly or renders through a web framework.
- `pptx_requires_conversion`: requires a converter or manual rebuild when a permitted PPTX exists.
- `manual_rebuild_recommended`: safer to rebuild in HTML because of source format or usage rights.
- `reference_only`: inspiration or theory reference, not a conversion target.
- `asset_reference`: candidate asset source for HTML/PPT production after license review.

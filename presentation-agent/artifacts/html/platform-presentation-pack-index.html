Platform Presentation Pack

개인 에이전트 플랫폼 발표 자료

현재 저장소의 플랫폼 철학, 운영 루프, 프로젝트 경계, 품질 게이트를 설명하는 전체 덱과 등록 루트 프로젝트별 deep dive 덱을 한 곳에서 연다.

전체 플랫폼 15 slides 25-35 min
AI Agent Workspace: 개인 에이전트 작업 OS 철학, 운영 루프, 공통 폴더, 조사 엔진, 요구사항/스펙, 평가와 히스토리 구조를 설명한다.
agent-platform 8 slides 10-15 min
에이전트가 일하는 방식을 제품화하는 중심 엔진 조사, 계획, 평가, grounding, memory, config contract, CLI 검사 구조를 설명한다.
workspace-monitor 7 slides 8-12 min
문서 기반 운영 상태를 웹에서 보이게 만든다 저장소 snapshot, Next.js UI, Vercel 배포 전 공개 범위 점검 흐름을 설명한다.
presentation-agent 8 slides 10-15 min
발표는 조사와 흐름의 결과다 레퍼런스 우선 정책, deck-spec, 발표자 노트, HTML/PPTX 제작 루프를 설명한다.

레퍼런스, 라이선스, 스크립트, HTML 덱, PPTX 후보를 하나의 제작 루프로 묶는다.

Reference First

먼저 많이 보고, 복제하지 않고 구조를 배운다

  • 발표 프레임워크와 HTML slide engine을 수집한다.
  • PPT 템플릿과 디자인 갤러리는 라이선스 확인 전까지 metadata로 둔다.
  • 에셋은 사용 가능성이 아니라 provenance와 license gate로 판단한다.

Deck Spec

발표 스크립트와 슬라이드는 JSON 계약으로 만난다

  • `script_beat`: 슬라이드가 이야기에서 맡는 역할
  • `speaker_notes`: 실제 발표자가 말할 순서
  • `evidence_sources`: 레퍼런스 카탈로그 기반 근거
  • `visual`: HTML/PPT 렌더러가 그릴 proof object

PPTX Loop

PPTX는 HTML 이후 editable 산출 후보로 연결된다

  • `artifact_pptx.py`는 deck-spec을 artifact-tool workspace로 변환한다.
  • 최종 PPTX export는 Presentations skill의 artifact-tool 경로를 우선한다.
  • 이번 플랫폼 발표 팩은 HTML 준비본을 먼저 완성한다.
  • framework-marp-official

License Gate

이번 덱은 외부 이미지 없이 자체 CSS와 내부 근거로 만든다

  • 원격 이미지와 무단 템플릿 복제를 사용하지 않는다.
  • 카탈로그 출처는 구조적 참고와 발표 이론 근거로만 사용한다.
  • 내부 소스 경로는 source notes와 speaker notes에 남긴다.
  • assets-lucide
no unknown-license assets
  1. 레퍼런스는 참고하되 복제하지 않습니다.
  2. 이번 산출물은 자체 HTML/CSS로 렌더링되며, 외부 이미지 에셋을 포함하지 않습니다.

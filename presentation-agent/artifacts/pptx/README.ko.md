# PPTX 산출물

이 폴더는 발표 에이전트가 생성한 editable PowerPoint 산출물을 보관한다.

## 현재 산출물

- `presentation-agent-kickoff.pptx`: `data/deck-specs/presentation-agent-kickoff.ko.json`에서 생성한 6장짜리 발표 에이전트 소개 PPTX.

## 생성 원칙

- PPTX는 `deck-spec`과 source notes를 근거로 생성한다.
- 디자인 요소가 추가로 필요하면 웹 검색, 출처 기록, 라이선스 게이트를 먼저 통과한다.
- 최종 PPTX export는 가능한 경우 Presentations skill의 artifact-tool 경로를 사용한다.

# 계획: PPT 레퍼런스 확장

1. 웹 검색으로 PPT/AI slide/template/gallery/research 출처를 확인하고 검색 기록을 저장한다.
2. 발표 에이전트 요구사항 기준선에 PPT 레퍼런스 확장, 사용자 제공 PPT 레퍼런스화, 일관성 있는 템플릿 생성을 추가한다.
3. `starter-reference-catalog.json`에 새 출처를 metadata-only 기본 정책으로 추가한다.
4. 사용자가 PPT를 가져왔을 때의 local-only 저장, 권한 확인, 텍스트 추출, 디자인 토큰화, template profile 생성 workflow를 문서화한다.
5. catalog/test/config/workspace 검증을 실행하고 평가/히스토리/요약/추적을 남긴다.

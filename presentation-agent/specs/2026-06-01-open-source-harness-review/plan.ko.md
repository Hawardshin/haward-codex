# 구현 계획

## 단계

1. 웹 검색으로 high-signal 하네스와 벤치마크를 확인한다.
2. 현재 `presentation-agent` 구조와 후보를 대조한다.
3. `harness-candidates.json`에 후보와 adoption gate를 저장한다.
4. `REQ-PA-014`와 workflow 문서를 추가한다.
5. 공유 연구 노트와 프로젝트 연구 노트를 남긴다.
6. history, timing, evaluation을 남기고 검증한다.

## 의사결정

- 새 설치는 보류한다.
- no-install static check를 첫 구현 대상으로 둔다.
- 브라우저/접근성 하네스는 설치 감사 이후로 둔다.
- LLM 평가 하네스는 프롬프트 계약 안정화 이후로 둔다.

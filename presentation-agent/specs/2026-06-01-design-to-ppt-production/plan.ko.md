# 계획: 디자인 요소 수집에서 PPT 생성까지

1. 웹 검색으로 PPTX 생성 라이브러리와 PresentationML 구조 참고점을 확인한다.
2. Presentations skill 지침을 읽고 artifact-tool export를 우선 경로로 정한다.
3. 디자인 요소 검색-수집-PPT 생성 워크플로 문서를 추가한다.
4. `deck-spec`을 artifact-tool slide module workspace로 변환하는 도구를 만든다.
5. 샘플 `deck-spec`으로 실제 PPTX를 생성한다.
6. 단위 테스트, PPTX 내부 구조 검증, contact sheet 시각 검토를 실행한다.
7. 요구사항, 히스토리, 평가, 커밋/푸시를 완료한다.

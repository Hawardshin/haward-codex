# 스펙: HTML 발표 덱과 스크립트 협업

## 목표

발표 스크립트 에이전트가 만든 슬라이드 흐름과 발표자 노트를 `deck-spec`으로 받고, 이를 PPT처럼 발표 가능한 HTML 덱으로 렌더링한다.

## 요구사항

- `deck-spec`은 제목, 언어, 테마, 레퍼런스 출처, 스크립트 협업 계약, 슬라이드 목록을 포함한다.
- 각 슬라이드는 `id`, `layout`, `title`, `script_beat`, `speaker_notes`, 선택적 `evidence_sources`를 포함한다.
- 렌더러는 16:9 슬라이드, 키보드 이동, 진행률, 발표자 노트 패널, 인쇄 스타일을 제공한다.
- 렌더러는 카탈로그 ID를 검증해 존재하지 않는 근거 출처를 막는다.
- 샘플 덱은 발표 에이전트 자체를 소개하는 실제 HTML 산출물이어야 한다.

## 비범위

- 이번 작업은 외부 HTML 발표 프레임워크를 설치하지 않는다.
- 이번 작업은 원격 이미지나 저작권 불명 에셋을 포함하지 않는다.

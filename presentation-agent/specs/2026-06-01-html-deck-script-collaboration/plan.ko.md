# 계획: HTML 발표 덱과 스크립트 협업

1. 웹 검색으로 HTML 발표 프레임워크의 speaker notes와 presenter mode 흐름을 확인한다.
2. 발표 스크립트 에이전트와 HTML 렌더러의 공유 계약인 `deck-spec` 구조를 만든다.
3. `html_deck.py` 렌더러를 작성해 `deck-spec`을 16:9 HTML 발표 덱으로 변환한다.
4. 발표 에이전트 소개용 샘플 `deck-spec`과 HTML 산출물을 만든다.
5. 단위 테스트로 spec 검증, 카탈로그 출처 검증, HTML 렌더링을 확인한다.
6. 원격 에셋이 없는지 정적 검증한다.
7. 히스토리, 평가, 커밋, 푸시를 완료한다.

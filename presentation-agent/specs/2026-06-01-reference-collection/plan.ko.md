# 계획: 발표 레퍼런스 수집 기반

1. 웹 검색으로 HTML 발표 프레임워크, PPT 템플릿 갤러리, 디자인 갤러리, 에셋 라이브러리, 발표 이론, 변환 도구 후보를 확인한다.
2. `presentation-agent/` 프로젝트를 생성하고 폴더 의미가 보이는 구조를 만든다.
3. 카탈로그 스키마에 해당하는 JSON 데이터와 수집 정책을 작성한다.
4. Python 카탈로그 검증 도구와 PPTX 텍스트-HTML 변환 도구를 작성한다.
5. 발표 레퍼런스 큐레이터 스킬을 만들고 레지스트리에 등록한다.
6. 요구사항, 스펙, 조사 요약, 히스토리, 평가를 기록한다.
7. 테스트와 스킬 검증을 실행한 뒤 커밋하고 푸시한다.

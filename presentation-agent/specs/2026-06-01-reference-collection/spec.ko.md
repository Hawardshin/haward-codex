# 스펙: 발표 레퍼런스 수집 기반

## 목표

`presentation-agent/` 프로젝트 안에 발표 디자인과 PPT/HTML 레퍼런스를 반복적으로 수집할 수 있는 데이터 구조, 검증 도구, 변환 진입점을 만든다.

## 사용자 요구 연결

- 발표 에이전트를 코딩 프로젝트와 분리된 새 프로젝트로 만든다.
- 예쁜 PPT와 HTML 발표 레퍼런스를 많이 모은다.
- PPT는 HTML로 바꿀 수 있는 구조를 마련한다.
- 레퍼런스와 에셋을 한 프로젝트에 둔다.

## 기능 요구

- 최소 50개 이상의 초기 출처 레코드.
- 각 레코드에 출처, 접근일, 라이선스 상태, 다운로드 가능성, HTML 변환 방식을 기록.
- 원본 저장 금지/허용 기준을 설정 파일로 명시.
- PPTX 텍스트 구조를 HTML로 변환하는 Python 도구 제공.
- 발표 레퍼런스 수집 스킬을 `_skills/`에 등록.

## 품질 요구

- 카탈로그 검증은 중복 ID, 필수 필드, URL 형식, 라이선스/다운로드 충돌을 잡아야 한다.
- 테스트는 카탈로그 폭과 PPTX 변환 기본 동작을 확인해야 한다.
- 문서와 히스토리는 한국어/영어 쌍으로 남긴다.

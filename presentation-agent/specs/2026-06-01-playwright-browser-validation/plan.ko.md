# 구현 계획

1. 설치 전 공식 문서와 이전 하네스 후보 설정을 확인한다.
2. 설치 감사 기록을 draft로 만든다.
3. `presentation-agent`에 Node package manifest와 Playwright config를 추가한다.
4. browser test를 `tests/browser/`에 둔다.
5. Playwright/axe dependency와 Chromium을 설치한다.
6. browser test를 실행하고 실패 원인을 수정한다.
7. 설치 기록, registry, 요구사항, README, workflow를 갱신한다.
8. history, timing, evaluation을 남긴다.

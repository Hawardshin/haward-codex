# Presentation Conversion Records

This folder stores PPT/PPTX-to-HTML conversion outputs and conversion notes. Every conversion output must link back to a source catalog record and license review.

## Conversion Rules

- The default converter extracts text structure and slide order into HTML.
- Open Impress template conversion does not render `.otp` files with visual fidelity; it creates HTML reference cards with thumbnails, provenance, license notes, and extracted text.
- Pixel-faithful visual conversion requires separate renderer research, screenshot verification, and license review.
- Conversion output filenames should include the source record ID and date.

# User-Provided PPT Raw Folder

This folder is a local-only place for temporary reference analysis of PPT/PPTX files provided by the user.

## Rules

- Raw PPT/PPTX files in this folder are not committed to git by default.
- Exceptions require explicit user permission and confirmed usage rights.
- Analysis results should become text structure, design tokens, layout archetypes, repeated components, and section rhythm instead of direct source copying.
- Conversion outputs or template profiles should record source file path, provider, usage purpose, and rights-confirmation status in a separate source note.

# 사용자 제공 PPT 원본 폴더

이 폴더는 사용자가 직접 제공한 PPT/PPTX를 임시로 두고 레퍼런스 분석을 하기 위한 local-only 위치다.

## 규칙

- 기본적으로 이 폴더의 원본 PPT/PPTX 파일은 git에 커밋하지 않는다.
- 사용자가 명시적으로 저장/커밋을 허가하고 사용 권한이 확인된 경우에만 예외를 검토한다.
- 분석 결과는 원본 복제가 아니라 텍스트 구조, 디자인 토큰, 레이아웃 archetype, 반복 컴포넌트, 섹션 리듬으로 저장한다.
- 변환 결과나 template profile을 만들 때는 원본 파일 경로, 제공자, 사용 목적, 권한 확인 상태를 별도 source note에 기록한다.

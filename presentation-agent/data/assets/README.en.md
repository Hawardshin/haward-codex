# Presentation Asset Store

This folder stores images, icons, fonts, illustrations, and reusable template pieces that can actually be used in presentation production. Raw storage is allowed only after license review.

## Subfolders

- `raw/`: source files, only after license, provenance, access date, and usage terms are checked.
- `raw/user-provided/`: local-only temporary analysis location for user-provided PPT/PPTX files. Raw files are not committed by default.
- `raw/open-impress-templates/files/`: license-cleared public LibreOffice Impress `.otp` template files.
- `html/`: assets reconstructed for HTML presentations.
- `pptx/`: PPTX originals or samples that are legal to keep locally.
- `thumbnails/`: catalog previews, subject to the original asset terms.
- `thumbnails/open-impress-templates/`: preview images for the public Impress template HTML gallery.

## Current Open Template Bundle

- `raw/open-impress-templates/files/`: 119 `.otp` templates collected from the `dohliam/libreoffice-impress-templates` GitHub archive on 2026-06-02.
- `thumbnails/open-impress-templates/`: 119 thumbnails from the same templates.
- Source, license, local file, and HTML conversion paths are recorded in `data/reference-index/open-impress-template-downloads.json`.

## Prohibited

- Do not bypass paid template access or store account-gated files.
- Do not store raw PPT or image files merely because they are visible online.
- Do not use unprovenanced assets as evidence or production inputs.

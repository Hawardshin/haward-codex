# 발표 에셋 저장소

이 폴더는 발표 자료 제작에 실제로 사용할 수 있는 이미지, 아이콘, 폰트, 일러스트, 템플릿 조각을 저장한다. 원본 저장은 라이선스가 확인된 경우에만 허용된다.

## 하위 폴더

- `raw/`: 원천 파일. 라이선스, 출처, 접근일, 사용 조건이 확인된 경우에만 저장한다.
- `html/`: HTML 발표로 재구성된 에셋.
- `pptx/`: 합법적으로 보관 가능한 PPTX 원본 또는 샘플.
- `thumbnails/`: 카탈로그 탐색용 미리보기. 썸네일도 원본 조건을 따른다.

## 금지

- 유료 템플릿 파일을 우회 다운로드해 저장하지 않는다.
- 온라인에서 볼 수 있다는 이유만으로 원본 PPT나 이미지를 저장하지 않는다.
- 출처 없는 에셋을 발표 에이전트의 학습/제작 근거로 쓰지 않는다.

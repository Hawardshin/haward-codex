# Licensing And Provenance Policy

## Principles

- Do not store illegally downloaded or source-unknown SVG files.
- The default usable assets are internally generated SVG files created by `scripts/generate_svg_assets.py`.
- External open-source SVGs stay as candidates until current license, source URL, access date, attribution, trademark/brand constraints, and public-use constraints are recorded.

## Current Asset Status

- The 600 SVG files under `assets/svg/generated/` were generated by the repository script and did not copy third-party SVG files.
- Before public redistribution, the repository owner should declare final license terms.
- External candidates are recorded in `data/asset-registry.json` under `external_source_candidates` with `downloaded=false`.
- Current candidates include Lucide, Heroicons, Tabler Icons, Bootstrap Icons, Google Material Symbols, OpenMoji, and Font Awesome Free.

## Prohibited Use

- Do not copy paid templates, commercial PPTs, brand assets, or marketplace assets without source and license review.
- Do not trace or clone a specific paid or branded design even when aiming for a similar mood.
- Do not store external SVG files without a license file or attribution record.

## Required Record For Stored External Assets

- Source URL
- License name and license URL
- Access date
- Attribution requirement
- Public/private use scope
- Modification permission
- Trademark/brand restrictions
- Stored file list

# Design Asset Library Requirements Baseline

## DAL-REQ-001 Legal Asset Principle

- Do not store external SVG files without license and provenance records.
- Use internally generated SVGs as the default asset source.

## DAL-REQ-002 Large SVG Inventory

- Prepare many SVG candidates across presentation, interface, workflow, abstract, status, and pattern families.
- Each SVG must have registry fields for id, path, family, motif, rights status, and tags.

## DAL-REQ-003 Regenerability

- The SVG pack must be reproducible through a deterministic generator.
- Registry and files should update together through one command.

## DAL-REQ-004 External Candidate Separation

- Open-source candidates such as Lucide, Heroicons, and Tabler stay in `external_source_candidates`; actual file storage happens only after license review.

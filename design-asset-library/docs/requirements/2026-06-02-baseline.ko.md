# 디자인 에셋 라이브러리 요구사항 기준선

## DAL-REQ-001 합법 자산 원칙

- 외부 SVG 파일은 license/provenance 기록 없이 저장하지 않는다.
- 기본 자산은 내부 생성 SVG를 사용한다.

## DAL-REQ-002 대량 SVG 준비

- 발표, UI, workflow, abstract, status, pattern 계열로 충분한 SVG 후보를 미리 준비한다.
- 각 SVG는 registry에 id, path, family, motif, rights status, tags를 가져야 한다.

## DAL-REQ-003 재생성 가능성

- SVG pack은 deterministic generator로 재생성 가능해야 한다.
- registry와 파일은 같은 명령으로 함께 갱신되어야 한다.

## DAL-REQ-004 외부 후보 분리

- Lucide, Heroicons, Tabler 같은 오픈소스 후보는 `external_source_candidates`에 기록하되, 실제 파일 저장은 license review 후에만 한다.

## DAL-REQ-005 쉬운 탐색과 사용

- 사용자는 JSON을 직접 읽지 않아도 계열별 집계, 검색, snippet, HTML gallery로 자산을 찾을 수 있어야 한다.
- HTML/PPT 산출물에 연결할 수 있는 경로와 `<img>` 예시를 도구가 생성해야 한다.
- 갤러리는 정적 HTML로 생성되어 별도 서버 없이 열 수 있어야 한다.

## DAL-REQ-006 실제 외부 SVG 수집

- 외부 오픈소스 SVG를 실제 저장할 때는 공식 repository, pinned commit, license URL, local `LICENSE`, local `SOURCE.json`, upstream path를 registry에 기록해야 한다.
- 수집기는 path allowlist를 사용해 docs, preview, brand, build output 같은 비대상 SVG를 제외해야 한다.
- 실제 수집 registry는 `data/external-asset-registry.json`에 따로 두고, 생성 자산 registry와 혼합하지 않는다.
- 수집 수량은 source별 limit로 제어하고, 확장은 정책 파일 변경과 재검증 후 수행한다.

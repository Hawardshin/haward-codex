# 디자인 에셋 라이브러리 요구사항 기준선

## DAL-REQ-001 합법 자산 원칙

- 외부 SVG 파일은 license/provenance 기록 없이 저장하지 않는다.
- 기본 자산은 내부 생성 SVG를 사용한다.

## DAL-REQ-002 대량 SVG 준비

- 발표, UI, workflow, abstract, status, pattern 계열로 충분한 SVG 후보를 미리 준비한다.
- 각 SVG는 registry에 id, path, family, motif, rights status, tags를 가져야 한다.

## DAL-REQ-003 재생성 가능성

- SVG pack은 deterministic generator로 재생성 가능해야 한다.
- registry와 파일은 같은 명령으로 함께 갱신되어야 한다.

## DAL-REQ-004 외부 후보 분리

- Lucide, Heroicons, Tabler 같은 오픈소스 후보는 `external_source_candidates`에 기록하되, 실제 파일 저장은 license review 후에만 한다.

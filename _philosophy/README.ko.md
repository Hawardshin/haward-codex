# 철학 라이브러리

이 폴더는 저장소 운영과 에이전트 설계의 근본 관점을 저장한다.

정책 문서는 `_docs/`, 실행 절차는 `_ops/`, 작업 기록은 `_history/`에 둔다. 이 폴더는 그 규칙들이 왜 필요한지 설명하는 상위 철학을 다룬다.

## 문서

- [에이전트 운영 철학](agent-operating-philosophy.ko.md)
- [플랫폼 컨셉 재검토](platform-concept-review.ko.md)

## 기록 기준

다음 내용은 `_philosophy/`에 둔다.

- 반복되는 사용자 관점이나 세계관
- 에이전트가 일하는 방식의 근본 원칙
- 정책과 워크플로의 이유
- 장기적으로 변하지 않아야 할 판단 기준

다음 내용은 다른 폴더에 둔다.

- 실행 규칙: `_docs/`
- 프롬프트와 워크플로: `_ops/`
- 작업 히스토리: `_history/`
- 리서치 근거: `_research/`

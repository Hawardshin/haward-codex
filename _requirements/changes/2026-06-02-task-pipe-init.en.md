# Task Pipe Init Requirements Change

- Date: 2026-06-02
- Request ID: `UR-2026-06-02-059`
- Request: Move toward initializing diverse CLIs for diverse tasks through a pipe-based structure.

## Added

- `PDA-REQ-027`: The Desktop supervisor shall initialize several optional CLI lanes from one task intake through a pipe graph.
- `PDA-UX-020`: The Desktop tab shall show task pipe preset, lane count, adapter list, pipe edges, merge gate, and missing-lane state.

## Non-Scope

- Installing or auto-installing external CLIs.
- Installing PTY, xterm.js, or the Tauri shell plugin.

# Requirements Change: Mode and Function Switchboard

## Change

- Added `REQ-WM-019` to the `workspace-monitor` requirements.
- Added `modeFunctionCatalog` and the Overview switchboard to scope as the explicit location map for modes and functions.

## Reason

- Users need to choose and locate many functions and modes easily on top of the multi-CLI orchestration platform.
- View/work/install/language/desktop session/task pipe/CLI adapter/section choices are spread across files and UI surfaces, so an explicit selection map is required.

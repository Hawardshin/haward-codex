# 요구사항 변경: Principle Guardian Agent

## 변경

`REQ-WS-067`을 추가한다.

플랫폼은 모든 에이전트가 원칙을 강하게 고수하도록 `principle-guardian-agent`와 영속 지침을 제공해야 한다.

## 이유

사용자는 “다들 강력하게 원칙을 고수한다”고 요청했다. 이미 여러 도메인 에이전트가 생겼으므로, 속도·돈·낙관·편의가 기존 원칙을 우회하지 못하도록 공통 원칙 보호 역할이 필요하다.

## 수용 기준

- 에이전트 설정과 문서가 존재한다.
- 영속 지침에 원칙을 close-out gate로 취급한다는 규칙이 남는다.
- 정책에 speed/profit/optimism/convenience shortcut 차단이 포함된다.
- 검증과 평가가 통과한다.

# 디자인 에셋 사용성 확장 요구사항 변경

## 변경 ID

- `REQ-WS-082`

## 사용자 의도

- 유용한 디자인 자산을 계속 많이 모으되, 사용자가 쉽게 찾고 사용할 수 있는 구조가 필요하다.

## 변경 내용

- `design-asset-library`의 내부 생성 SVG 수량을 600개로 확장한다.
- 자산을 JSON 직접 탐색에만 의존하지 않고 `families`, `search`, `snippet`, `gallery` 흐름으로 사용할 수 있게 한다.
- 갤러리는 정적 HTML로 생성해 별도 서버 없이 열 수 있게 한다.
- 외부 오픈소스 아이콘/이모지 후보는 계속 후보로만 기록하고, 파일 저장은 license review 후에만 한다.

## 근거

- 기존 120개 생성 자산은 법적 안전성은 있으나, 사용자가 빠르게 고르기에는 탐색 구조가 약했다.
- 발표, HTML artifact, dashboard, prototype 작업은 시각 후보를 빠르게 훑고 바로 붙일 수 있는 도구가 필요하다.

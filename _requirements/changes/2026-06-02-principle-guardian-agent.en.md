# Requirement Change: Principle Guardian Agent

## Change

Add `REQ-WS-067`.

The platform shall provide `principle-guardian-agent` and persistent instructions so all agents strongly adhere to principles.

## Reason

The user said that everyone strongly adheres to principles. Since many domain agents now exist, a shared principle-protection role is needed so speed, money, optimism, and convenience cannot bypass existing principles.

## Acceptance Criteria

- Agent config and docs exist.
- Persistent instructions record that principles are close-out gates.
- The policy blocks speed/profit/optimism/convenience shortcuts.
- Verification and evaluation pass.

# Requirement Change: Profit Analyst Agent

## Change

Add `REQ-WS-066`.

The platform shall provide `profit-analyst-agent`, which evaluates work, projects, products, features, pricing, outsourcing, automation, and infrastructure cost from a money and profit perspective.

## Reason

The user asked for a money/profit-side expert. The platform should reduce repeated work and also judge which work has real monetary value.

## Acceptance Criteria

- Agent config and docs exist.
- The output contract includes revenue/cost drivers, ROI/NPV/payback/break-even/unit economics, scenario/sensitivity, and source provenance.
- The policy includes high-risk financial-advice limits, professional review, human checkpoints, and non-financial constraints.
- Verification and evaluation pass.

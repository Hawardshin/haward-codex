## 판단

사용자 지시는 앞으로의 UI 설계에 반복 적용되어야 하는 지속 지시다. 기존 UI tone policy는 명확성, 훑어보기, 접근성, 운영 신뢰를 다루고 있었지만, 단일 주 기능 화면의 공간 배분 기준은 명시하지 않았다. 따라서 새로운 요구사항을 별도 UI focus gate로 수용한다.

## 충돌 검토

- 기존 "운영 도구처럼 빠르게 읽히는 UI" 원칙과 충돌하지 않는다.
- 기존 "장식 과잉과 시각적 소음 회피" 원칙을 더 구체화한다.
- dashboard나 monitor처럼 여러 상태를 동시에 봐야 하는 화면은 예외가 아니라 `비교`, `monitoring`, `다중 주 작업` 사유를 명시해야 하는 대상으로 분류한다.

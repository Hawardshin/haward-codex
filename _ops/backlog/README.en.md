# Operations Backlog

## Purpose

This folder tracks non-blocking improvements intentionally deferred by `ship_first` mode or lightweight work.

## Rules

- Do not defer failed verification, mismatches with the user request, unsupported factual claims, or missing installation audits.
- Each backlog item records why it was deferred, revisit triggers, related artifacts, and owning scope.
- Project-specific improvements belong in the owning project's backlog or docs.
- This folder is only for shared operations improvements.

## Key Files

- [deferred-improvements.ko.md](deferred-improvements.ko.md): shared deferred improvement list
- [deferred-improvements.en.md](deferred-improvements.en.md): English companion

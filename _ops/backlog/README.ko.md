# 운영 백로그

## 목적

`ship_first` 모드나 빠른 작업에서 의도적으로 뒤로 뺀 비차단 개선을 한 곳에서 관리한다.

## 규칙

- 검증 실패, 사용자 요청 불일치, 근거 없는 사실 주장, 설치 감사 누락은 백로그로 미루지 않는다.
- 백로그 항목은 미룬 이유, 다시 볼 조건, 관련 산출물, 소유 범위를 포함한다.
- 프로젝트 전용 개선은 해당 프로젝트 안의 백로그나 문서에 둔다.
- 공통 운영 개선만 이 폴더에 둔다.

# Create Project Prompt

Use when: 새 루트 프로젝트를 만들어야 할 때.

## Prompt

```text
새 프로젝트는 루트의 kebab-case 폴더로 만든다.
Python 에이전트 성격이면 _templates/python-agent-project/를 우선 참고한다.
일반 프로젝트면 _templates/project/를 참고한다.
README, docs, artifacts, tests 구조를 만들고, 필요한 경우 src를 둔다.
_ops/maps/와 _history/를 업데이트한 뒤 커밋하고 즉시 push한다.
```

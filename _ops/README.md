# Operations Hub

이 폴더는 저장소를 오래 운영할수록 반복 탐색을 줄이기 위한 시작점이다.

## Start Here

1. [_ops/index.md](index.md)에서 현재 저장소의 길잡이를 확인한다.
2. [_ops/prompts/00-router.md](prompts/00-router.md)에서 작업 성격에 맞는 프롬프트를 고른다.
3. [_ops/workflows/00-start-here.md](workflows/00-start-here.md)에서 작업 순서를 확인한다.
4. 변경 후 [_ops/maps/](maps/)를 갱신한다.

## Folder Shape

```text
_ops/
  README.md
  index.md
  prompts/
  workflows/
  maps/
  artifacts/
```

## Rules

- 새 운영 절차가 반복되면 `workflows/`에 추가한다.
- 재사용할 프롬프트는 `prompts/`에 추가한다.
- 어디에 무엇이 있는지 바뀌면 `maps/`를 갱신한다.
- 장기 기억은 대화가 아니라 이 저장소 문서에 남긴다.

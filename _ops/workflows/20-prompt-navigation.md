# Prompt Navigation Workflow

## Purpose

작업 성격에 따라 어떤 프롬프트를 써야 하는지 빠르게 결정한다.

## Sequence

1. Open [_ops/prompts/00-router.md](../prompts/00-router.md).
2. Choose the closest prompt.
3. If two prompts apply, use the more specific one first.
4. If no prompt fits and the pattern is likely to repeat, add a new prompt.
5. Run the workspace index tool after adding or renaming prompts.

## Output

- Selected prompt
- New prompt candidate, if needed

# 프로젝트 등록부

이 폴더는 루트 프로젝트의 상태와 경계를 추적한다.

## 파일

- `registry.json`: 프로젝트 등록 원본 데이터
- `index.ko.md`: 사람이 읽는 한국어 요약
- `index.en.md`: 영어 companion 요약

## 규칙

- 새 루트 프로젝트를 만들면 `registry.json`에 등록한다.
- 프로젝트의 목적, 상태, 소유 경계, 관련 공통 도구를 기록한다.
- 프로젝트별 파일은 해당 프로젝트 폴더 안에 둔다.
- 공통 도구나 정책으로 승격한 경우 관련 경로를 등록부에 남긴다.
- 프로젝트를 중단하거나 보관하면 상태를 업데이트하고 필요하면 `_archive/`로 옮긴다.

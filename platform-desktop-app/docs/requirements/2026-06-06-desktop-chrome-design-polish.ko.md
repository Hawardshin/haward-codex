# 데스크톱 크롬 디자인 개선 요구사항

## 배경

사용자는 앱 전체 디자인이 평면적이고 기본 버튼 느낌이 강하며 탭/사이드바/설정 선택 흐름의 직관성이 떨어진다고 반복적으로 지적했다. 이번 변경은 모바일 대응을 다시 늘리지 않고, 데스크톱 앱의 최소 창 크기와 넓은 작업면을 전제로 공통 크롬, 레일, 탭, 버튼, 패널의 시각 계층을 강화한다.

## 요구사항

- REQ-DESIGN-POLISH-001: 상단바, 좌측 레일, 섹션 탭, 패널은 공통 elevation/shadow 토큰을 사용해 깊이와 상태 차이를 보여야 한다.
- REQ-DESIGN-POLISH-002: 좌측 활동 레일은 `aria-current="page"`와 active 상태 모두에서 명확한 선택 표시와 readable label을 유지해야 한다.
- REQ-DESIGN-POLISH-003: 섹션 탭과 패널 헤딩 버튼은 기본 브라우저 버튼처럼 보이지 않도록 선택 배경, border, shadow, active 상태를 가져야 한다.
- REQ-DESIGN-POLISH-004: 공통 버튼은 hover/press/focus 상태에서 안정적인 시각 피드백을 제공하되 레이아웃을 흔들지 않아야 한다.
- REQ-DESIGN-POLISH-005: dark/system 테마에서도 선택/검색/깊이 토큰이 누락되지 않아야 한다.
- REQ-DESIGN-POLISH-006: 변경 후 정적 테스트, 렌더러 테스트, 앱 check, 빌드, 내부 패키징, 브라우저 smoke 검증을 실행해야 한다.

## 비범위

- 전체 정보 구조나 기능 배치를 새 IA로 재작성하지 않는다.
- 모바일 UI를 되살리지 않는다.
- 네이티브 윈도우 크롬, Tauri 명령, Rust 런타임은 이번 디자인 패치의 직접 변경 대상이 아니다.

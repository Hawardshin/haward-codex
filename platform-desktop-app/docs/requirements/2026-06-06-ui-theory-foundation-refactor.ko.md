# UI 이론 기반 디자인 파운데이션 리팩토링 요구사항

## 배경

사용자는 데스크톱 앱 UI를 단순 취향 수정이 아니라 UI 디자인 전문가 관점에서 이론을 학습한 뒤 리팩토링하라고 요청했다. 기존 화면은 일부 버튼, 선택 상태, 설정/홈 표면의 시각 위계가 기능별로 흩어져 있어 화면 간 일관성이 약해질 위험이 있었다.

## 요구사항

- REQ-UI-THEORY-001: 전역 UI foundation은 4px spacing, 표면 depth, hover/active/focus 상태를 명시적인 CSS 토큰으로 제공해야 한다.
- REQ-UI-THEORY-002: 홈, 설정, 어댑터 카드, 주요 선택/버튼 표면은 같은 hierarchy/depth 토큰을 사용해 시각 위계를 공유해야 한다.
- REQ-UI-THEORY-003: 키보드 포커스는 버튼뿐 아니라 링크, 입력, 탭, 커스텀 버튼 역할에도 보이는 halo와 outline을 제공해야 한다.
- REQ-UI-THEORY-004: dark/system 테마에서 depth 토큰이 light surface로 계산되지 않아야 한다.
- REQ-UI-THEORY-005: 리팩토링은 화면에 디자인 이론 설명 문구를 추가하지 않고 실제 조작/표면 상태로만 반영해야 한다.
- REQ-UI-THEORY-006: 구현 후 정적 테스트, check 게이트, 브라우저 렌더 검증, 내부 패키징 빌드를 실행해야 한다.

## 비범위

- 전체 제품 정보 구조를 새로 설계하지 않는다.
- 모든 상세 화면의 개별 컴포넌트를 한 번에 재작성하지 않는다.
- 모바일 중심 UI를 추가하지 않는다.

# CLI 설정 직관성 요구사항

- 날짜: 2026-06-06
- 소유 프로젝트: `platform-desktop-app`
- 작업 모드: `standard`
- 요청 요약: 사용자가 CLI 사용법과 설정 방법을 전혀 모르겠고, 설정이 직관적이지 않다고 지적했다.

## 요구사항

1. CLI 어댑터 설정은 단순 텍스트 목록이 아니라 설치, 로그인/키, 검증, 첫 실행의 순서가 보이는 단계형 안내여야 한다.
2. 각 CLI는 사용자가 바로 복사하거나 확인할 수 있는 명령 후보를 제공해야 한다.
3. CLI가 설치되지 않았거나 계정이 연결되지 않은 경우, 전체 앱을 막지 않고 해당 어댑터 카드에서 누락 이유와 다음 행동을 보여야 한다.
4. Agent CLI Cockpit은 실행 상태뿐 아니라 설정 준비 상태도 보여야 한다.
5. 설정 UI의 버튼은 같은 크기의 범용 버튼 나열이 아니라 목적별 상태, 선택, 복사, 실행을 구분해야 한다.
6. 브라우저 미리보기에서는 실제 설치/실행을 강제하지 않고, 네이티브 데스크톱 런타임에서 실행 가능하다는 한계를 표시해야 한다.

## 수용 기준

- 설정의 `CLI 어댑터` 섹션에서 선택된 CLI의 설치 명령, 로그인/키 힌트, 검증 명령, 첫 실행 명령을 볼 수 있다.
- Agent CLI Cockpit 카드마다 설치, 계정, 검증, 선택 단계가 표시된다.
- 명령 복사 버튼은 실행 버튼과 분리되어야 한다.
- 기존 Provider Accounts 패널과 연결되어 계정 필요/연결됨 상태가 CLI 카드에 반영된다.
- 테스트가 새 안내 UI의 데이터 속성, CSS 클래스, 명령 복사 표면을 검증한다.

## 근거

- Fluent 2 Onboarding: 맥락 안에서 필요한 순간에 단계별 안내와 실행 가능한 행동을 제공한다.
- Microsoft command bar flyout guidance: 관련 명령을 사용자가 작업 중인 요소 가까이에 배치한다.
- 기존 `platform-desktop-app/configs/user-flow-registry.json`: optional CLI는 누락 시 앱 전체를 막지 않고 setup guidance로 degrade해야 한다.

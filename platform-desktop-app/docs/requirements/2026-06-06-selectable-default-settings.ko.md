# 선택 가능한 기본 설정 요구사항

## 배경

사용자는 기본 설정과 실행 입력이 깡 텍스트로 노출되어 어떤 값을 넣어야 하는지 알기 어렵다고 지적했다. 텍스트 값이 필요한 설정도 먼저 선택지를 제시하고, 필요할 때 직접 수정할 수 있어야 한다.

## 요구사항

- REQ-SELECT-DEFAULT-001: 런타임 세션의 작업 폴더는 현재 작업공간, 저장소 루트, 런타임 기본값 같은 선택지를 제공해야 한다.
- REQ-SELECT-DEFAULT-002: 런타임 세션의 초기 입력은 세션 모드 프리셋을 선택 버튼으로 제공해야 한다.
- REQ-SELECT-DEFAULT-003: 작업 파이프라인 초기화 요청은 파이프 프리셋과 구현/조사/검토 목적별 선택지를 제공해야 한다.
- REQ-SELECT-DEFAULT-004: 검색 에이전트의 제공자와 모델 설정은 native select/datalist 의존을 줄이고 명시적 선택 버튼을 제공해야 한다.
- REQ-SELECT-DEFAULT-005: 선택 뒤에도 직접 텍스트 편집은 가능해야 한다.
- REQ-SELECT-DEFAULT-006: 긴 경로, 모델명, 설명 텍스트가 버튼 안에서 잘리지 않아야 한다.
- REQ-SELECT-DEFAULT-007: 구현 후 렌더러 검사, 앱 검사, 내부 패키징 빌드를 실행해야 한다.

## 비범위

- 모든 자유 입력 필드를 제거하지 않는다. 계정 비밀값, 저장소 URL, 임의 경로처럼 사용자가 실제로 직접 입력해야 하는 값은 직접 입력을 유지한다.
- 공개 배포 서명, notarization, updater, clean-machine smoke 문제는 이번 UI 개선 범위가 아니다.

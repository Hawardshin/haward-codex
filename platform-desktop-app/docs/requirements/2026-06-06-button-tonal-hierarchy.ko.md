# 버튼 톤/크기 계층 요구사항

## 배경

사용자는 기본 선택지, 검색/찾기 동작, 짧은 내용의 버튼이 과하게 크고 전체 색상이 비슷해 눈이 불편하다고 지적했다. 선택과 검색은 더 명확한 표면 계층을 가져야 하며, 내용이 적은 버튼은 compact하게 보여야 한다.

## 요구사항

- REQ-BUTTON-TONE-001: 설정 세그먼트처럼 짧은 선택 버튼은 전체 폭을 불필요하게 차지하지 않아야 한다.
- REQ-BUTTON-TONE-002: 선택, 검색, 결과 버튼은 배경 톤과 그림자로 일반 표면과 구분되어야 한다.
- REQ-BUTTON-TONE-003: 활성 선택 상태는 색상, border, shadow로 비활성 상태와 명확히 구분되어야 한다.
- REQ-BUTTON-TONE-004: 검색 입력과 커맨드 팔레트 결과는 더 읽기 쉬운 표면 계층을 가져야 한다.
- REQ-BUTTON-TONE-005: 변경 후 렌더러 검사, 앱 검사, 내부 패키징 빌드를 실행해야 한다.

## 비범위

- 전체 디자인 시스템을 새 테마로 교체하지 않는다.
- 주요 기능 카드처럼 정보량이 많은 버튼을 모두 작게 만들지는 않는다.

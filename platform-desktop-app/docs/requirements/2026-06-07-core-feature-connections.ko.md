# 요구사항: Core Feature Connections

날짜: 2026-06-07

## 요구

사용자는 주요 기능을 서로 연결해, 홈 화면의 핵심 기능이 단순 설명 카드로 끝나지 않고 실제 에이전트, 툴, 실행, 평가, 파일, 가시성 작업면으로 바로 이어지기를 요구했다.

## 수용 기준

- 홈의 핵심 기능 상세는 기본 CTA 외에 세부 연결 버튼을 제공한다.
- 연결 버튼은 섹션 이름만 여는 것이 아니라 해당 작업 의도와 단계까지 선택한다.
- 에이전트 만들기, 툴 만들기, 작업 실행, 평가, 파일 열기, 실행/결정 가시성의 주요 경로가 모두 포함된다.
- Tool Studio 연결은 선택된 tool mode 요청을 함께 전달한다.
- 연결 UI는 작은 화면에서 기존 홈 반응형 규칙을 따른다.
- 연결 DOM contract와 CSS contract가 테스트로 보호된다.

## 비범위

- 새 native command 추가.
- 실제 CLI 실행 pipeline 변경.
- 새로운 외부 dependency 설치.

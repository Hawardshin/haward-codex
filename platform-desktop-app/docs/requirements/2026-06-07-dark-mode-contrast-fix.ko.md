# Requirements: Dark Mode Contrast Fix

날짜: 2026-06-07

## 요청

사용자가 다크모드 색상 문제 해결을 요청했다.

## 요구사항

- 다크 모드에서 실제 표시되는 텍스트와 배경의 낮은 대비를 찾아 수정한다.
- 작은 텍스트는 WCAG 2.2 1.4.3의 일반 텍스트 대비 기준인 4.5:1 이상을 목표로 한다.
- 다크 배경 위 강조색 텍스트로 쓰이는 `--accent-primary`는 무리하게 어둡게 만들지 않는다.
- 흰 텍스트가 올라가는 선택/배지 배경은 `--control-selected-bg` 계열을 사용한다.
- 색상 토큰 테스트와 UI 구조 테스트로 재발을 막는다.

## 범위

- 포함: workspace monitor 다크 모드 터미널 런처 배지 대비, 색상 토큰 테스트, 관련 기록.
- 제외: 전체 다크 테마 재디자인, 브랜드 팔레트 교체, 새 라이브러리 설치.

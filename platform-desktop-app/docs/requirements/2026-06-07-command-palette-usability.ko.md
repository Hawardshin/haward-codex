# 요구사항: Command Palette Usability

날짜: 2026-06-07

## 요구

사용자는 확실한 기능 및 사용성 개선을 요구했다. 플랫폼 데스크톱 앱의 명령 팔레트는 이미 검색과 실행을 제공하지만, 검색 결과 수, 빈 결과 상태, 다음에 누를 수 있는 핵심 액션이 부족해 사용자가 막혔을 때 흐름이 끊긴다.

## 수용 기준

- 명령 팔레트는 현재 검색 결과 상태를 시각적으로 표시하고 보조기기에 `role="status"`로 알린다.
- 기본 상태에서는 핵심 설정, 챗봇 연결, 터미널, 실행 설정 같은 추천 명령을 먼저 보여준다.
- 검색 결과가 없을 때는 단순 빈 문구가 아니라 빈 결과 안내와 대체 추천 명령을 제공한다.
- 추천 명령 버튼은 기존 `Button` primitive를 사용하고 최소 조작 영역과 말줄임 규칙을 지킨다.
- 변경은 명령 팔레트 UI와 CSS에 한정하고, 새 전역 의존성이나 설치를 요구하지 않는다.
- 구조 테스트는 추천 명령, live status, 빈 결과 상태가 유지되는지 보호한다.

## 비범위

- 새 CLI adapter 설치.
- 새 native command 추가.
- 명령 검색 랭킹 엔진 교체.
- packaged Tauri 배포 정책 변경.

# 요구사항: Editable Runtime Prompts

날짜: 2026-06-07

## 요구

사용자는 각 프롬프트를 변경 가능하게 만들기를 요구했다. Desktop Runtime의 세션 초기 입력과 작업 파이프라인 초기화 프롬프트는 선택지만 제공하는 수준을 넘어, 선택한 프롬프트별로 직접 수정하고 다시 사용할 수 있어야 한다.

## 수용 기준

- 세션 초기 입력 프롬프트 선택지는 각 프롬프트 key를 가진다.
- 작업 파이프라인 프롬프트 선택지는 각 프롬프트 key를 가진다.
- 사용자는 현재 선택한 프롬프트의 textarea 내용을 저장할 수 있다.
- 저장된 프롬프트는 같은 key를 다시 선택할 때 기본값 대신 사용된다.
- 사용자는 저장된 프롬프트를 기본값으로 되돌릴 수 있다.
- 저장된 프롬프트는 데스크톱 runtime preferences에 보존된다.
- 네이티브 preferences 정규화는 허용된 프롬프트 key만 저장하고 빈 값과 알 수 없는 key를 제거한다.
- 선택/저장/초기화 UI contract와 네이티브 정규화 contract는 테스트로 보호된다.

## 비범위

- 새 CLI 실행 adapter 추가.
- 외부 prompt marketplace 또는 원격 동기화.
- 프롬프트 버전 이력 UI.
- provider별 prompt 템플릿 엔진.

사용자가 바로 쓸 수 있는 설치형 에이전트 플랫폼 흐름

설치형 프로그램의 첫 목표는 모든 설정을 끝내게 하는 것이 아니라 워크스페이스를 열고 현재 상태를 이해하게 하는 것이다. 선택 기능은 나중에 설정하고, 막힌 질문은 결정함에 모으며, 개발자 내부 도구는 슈퍼어드민 모드에서 다룬다.

첫 실행 흐름

01

시작

기존 워크스페이스 열기, 새 워크스페이스 만들기, 데모로 둘러보기.

02

범위 확인

어떤 문서와 설정을 읽고 어떤 스냅샷을 만들지 명확히 확인.

03

보기 모드

기본은 user, 고급 사용자는 developer 또는 superadmin_developer.

04

준비 검사

필수 문제만 막고, 선택 CLI와 알림은 설정 카드로 보류.

05

대시보드

진행 중 작업, 막힌 질문, 프로젝트, 히스토리, 새 작업 시작.

홈 정보 구조

사용자 모드

user
  • Now, Projects, Run, History 중심
  • 작업 시작과 결과 검토를 우선
  • raw config와 검증 내부 구조는 숨김

개발자 모드

developer
  • Capabilities 영역 표시
  • 에이전트, CLI, 알림, 검증 상태 확인
  • 스펙과 설정 변경 흐름 지원

슈퍼어드민 개발자

superadmin
  • raw registry와 정책 전체 확인
  • coordination, release gate, validation gap 확인
  • 제품화와 플랫폼 개선을 함께 관리

작업 실행 흐름

입력은 작게

  • 목표
  • 대상 프로젝트 또는 워크스페이스
  • 원하는 산출물

진행은 투명하게

  • 현재 단계와 경과 시간
  • 활성 에이전트와 subprocess
  • 생성 파일, 근거, 검증, 커밋/푸시 상태

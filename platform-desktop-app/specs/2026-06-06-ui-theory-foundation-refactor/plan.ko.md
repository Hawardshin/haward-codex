# UI 이론 기반 디자인 파운데이션 리팩토링 계획

## 실행 순서

1. 공신력 있는 UI/UX 이론 출처를 확인하고 현재 앱 문제와 매핑한다.
2. 전역 CSS token을 spacing, depth, state, focus 중심으로 확장한다.
3. 홈/설정/어댑터 카드/버튼 표면을 새 token으로 연결한다.
4. shell marker와 정적 테스트/readiness token을 추가한다.
5. 테스트, check, 브라우저 렌더 검증, 내부 패키징 빌드를 실행한다.

## 설계 판단

- 앱 구조를 갈아엎기보다 foundation token과 대표 표면을 먼저 맞춘다.
- 사용자가 볼 수 있는 설명 문구는 추가하지 않고, 조작 가능성/위계/상태 피드백으로 개선을 표현한다.
- CSS 중심 리팩토링을 선택해 React 상태 구조와 Rust 런타임 안정성을 건드리지 않는다.

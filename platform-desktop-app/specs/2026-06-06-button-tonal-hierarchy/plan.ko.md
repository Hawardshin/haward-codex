# 구현 계획

1. 선택/검색 표면에 쓰는 공통 색상 및 그림자 토큰을 추가한다.
2. 설정 탭, subsection rail, segment, option, pin 버튼에 토큰을 적용한다.
3. 커맨드 팔레트, 검색 박스, 검색 결과 버튼의 높이와 그림자를 조정한다.
4. 런타임 선택 카드, 검색 에이전트 provider/model 선택 카드의 높이와 active 상태를 조정한다.
5. 소스 툴바와 워크벤치 전환 버튼을 compact하고 tonal하게 만든다.
6. 정적 테스트로 compact/tonal 계약을 고정한다.
7. test/check/package 검증을 실행한다.

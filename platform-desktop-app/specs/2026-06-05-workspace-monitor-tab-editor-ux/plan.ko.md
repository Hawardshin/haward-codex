# 계획: Workspace Monitor 탭 전환과 소스 편집 UX

## 실행 순서

1. 탭 지연 렌더링 구조 확인.
2. 섹션 커밋을 즉시 처리하고 모듈 선로딩 추가.
3. 소스 편집 패널 상태 보존과 숨김 상태 리소스 가드 추가.
4. 사이드바와 소스 편집 CSS 계약 조정.
5. 테스트, 타입/정적 체크, 고객용 빌드, 브라우저 스모크 실행.

## 선택한 구현 옵션

- 선택: 기존 React/Next/Monaco 구조 유지.
- 대안으로 전체 탭 패널을 모두 상시 실행하는 방식은 런타임 폴링과 파일 시스템 작업 중복 위험이 있어 제외했다.
- 소스 편집 패널만 마운트 유지하고, 무거운 동적 모듈은 idle 선로딩으로 처리했다.

## 리스크 제어

- 숨겨진 소스 패널이 런타임 요청을 소비하지 않도록 `surfaceActive`를 추가했다.
- 정적 고객 스냅샷에서는 실제 파일이 없어 Monaco 편집 본문이 뜨지 않는 제한을 브라우저 검증에 기록했다.

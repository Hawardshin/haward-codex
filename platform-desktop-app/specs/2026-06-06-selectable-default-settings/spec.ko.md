# 선택 가능한 기본 설정 스펙

## 목표

기본 실행 설정과 모델 실행 설정에서 사용자가 텍스트를 처음부터 작성하지 않아도 되도록 선택 가능한 프리셋을 제공한다. 선택지는 버튼형 카드로 표시하고, 기존 텍스트 입력은 선택 후 세부 조정용으로 유지한다.

## 변경 대상

- `components/workbench/RuntimeTerminalDrawer.tsx`
- `components/MonitorShell.tsx`
- `app/globals.css`
- `tests/tool-studio.test.mjs`

## 동작

- 하단 런타임 터미널 시작 화면:
  - 작업 폴더 선택지: 런타임 기본, 현재 작업공간, 저장소 루트, 입력한 가져오기 경로 후보
  - 초기 입력 선택지: 현재 세션 모드와 주요 세션 모드 프리셋
- 작업 파이프라인 초기화:
  - 선택 프리셋, 구현 분해, 근거 조사, 검토/검증 요청 프리셋
- 검색 에이전트 실행 설정:
  - 제공자 계정은 버튼형 선택지
  - 모델은 기본 모델, 발견된 모델, 현재 직접 입력값을 버튼형 선택지로 제공
  - datalist 기반 모델 선택은 제거

## UI 계약

- 선택 버튼은 `aria-pressed` 또는 `aria-selected`를 제공한다.
- 선택지는 긴 텍스트를 `overflow-wrap: anywhere`로 감싼다.
- 텍스트 필드는 직접 편집 가능해야 한다.
- 터미널 드로어의 어두운 터미널 표면에서는 터미널 색상 토큰을 사용한다.

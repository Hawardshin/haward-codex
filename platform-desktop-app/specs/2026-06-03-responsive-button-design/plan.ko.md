# Plan: Responsive Button Design

1. 공식 UI/accessibility 기준을 확인한다.
2. 현재 CSS의 button group 분산 상태를 조사한다.
3. 공통 button token과 기본 button interaction contract를 추가한다.
4. titlebar, panel, settings, terminal, source, workspace action buttons를 responsive rule에 포함한다.
5. readiness test에 button responsive token을 추가한다.
6. desktop/mobile browser smoke로 target size와 overflow를 확인한다.
7. history/evaluation을 남기고 commit/push한다.

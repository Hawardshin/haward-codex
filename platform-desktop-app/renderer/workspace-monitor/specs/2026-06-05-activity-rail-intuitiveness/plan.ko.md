# 계획: Activity Rail Intuitiveness

1. 최신 UX 기준에서 recognition, navigation rail label 기준을 확인한다.
2. 현재 activity rail의 DOM/CSS 구조를 점검한다.
3. 기본 레일 폭과 nav button layout을 아이콘+라벨 구조로 조정한다.
4. 모바일 상단 레일에서도 라벨이 유지되도록 flex-basis와 span visibility를 조정한다.
5. utility icon button에 `aria-label`을 보강한다.
6. 정적 테스트와 브라우저 smoke로 라벨 표시, active state, overflow를 검증한다.

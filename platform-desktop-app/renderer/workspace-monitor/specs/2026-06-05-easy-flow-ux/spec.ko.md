# Easy Flow UX 스펙

## 요구사항

- REQ-WM-046: 목표 기반 이동 후 대상 작업면은 3개 이하의 짧은 순서형 작업 흐름을 표시해야 한다.

## 사용자 결과

- 사용자는 `툴 만들기` 선택 후 Tool Studio에서 `소스 선택`, `입력과 venv 확인`, `검증 후 배포` 순서를 즉시 확인한다.
- 사용자는 전체 기능 목록을 해석하기 전에 현재 목표의 다음 진행 순서를 먼저 본다.

## 비목표

- 각 단계별 상세 wizard 구현
- 사용자 진행 상태의 장기 저장
- 모든 섹션에 독립 breadcrumb 시스템 도입

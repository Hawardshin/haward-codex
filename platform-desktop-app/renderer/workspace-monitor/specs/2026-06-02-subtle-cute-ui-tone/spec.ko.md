# Spec: Subtle Cute UI Tone

## 요청

사용자는 플랫폼 UI가 은근히 귀여운 것도 좋다고 했다.

## 목표

- Workspace Monitor가 운영 도구의 가독성, 밀도, 신뢰를 유지한다.
- 작은 색상 신호와 micro-interaction으로 조용히 기분 좋은 톤을 반영한다.
- 이 톤을 공통 UI 정책과 요구사항에 연결해 future UI 작업에서 재사용한다.

## 요구사항 연결

- `REQ-WS-062`
- `REQ-WM-014`

## 범위

- 공통 persistent instruction
- UI tone policy
- Workspace Monitor CSS tone adjustment
- README, 요구사항, history, evaluation

## 제외 범위

- 대규모 visual redesign
- mascot, emoji-heavy UI, decorative illustration
- 데이터 모델, snapshot schema, real-time UI 변경

# 구현 계획

1. `AgentCoreCapabilityOption` catalog를 추가한다.
2. `buildAgentFactoryFormFromAgentCoreBlueprint`가 selected capability IDs를 받게 한다.
3. AgentCore Quick Builder에 capability bundle selector를 추가한다.
4. Apply/Preflight/Create proposal action이 selected capability IDs를 전달하게 한다.
5. CSS와 정적 테스트 계약을 추가한다.
6. desktop/mobile browser smoke를 실행한다.

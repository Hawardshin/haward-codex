# Overview Focus Command Surface 스펙

## 요구사항

- REQ-WM-057: Overview 첫 화면은 하나의 추천 작업, 다음 단계 preview, primary action을 먼저 보여주는 Focus Command Surface여야 한다.

## 사용자 결과

- 사용자는 Overview 첫 화면에서 동등한 카드 목록보다 먼저 추천 작업 하나와 다음 단계 3개를 본다.
- 사용자는 primary action으로 바로 대상 작업면에 들어간다.
- 다른 목표는 별도 작업 dock에 남아 있어 필요할 때만 선택한다.
- 현재 작업량은 보조 status strip으로 낮아져 첫 판단을 방해하지 않는다.

## 비목표

- 전체 제품 UI를 한 커밋에서 전면 재작성
- 새 디자인 시스템 라이브러리 설치
- 실제 agent/tool runtime 동작 변경
- 운영/문서/히스토리 섹션의 정보 구조 전면 재편

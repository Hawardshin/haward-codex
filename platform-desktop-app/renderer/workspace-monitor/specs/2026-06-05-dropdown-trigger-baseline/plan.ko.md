# 계획: Dropdown Trigger Baseline

1. 웹 접근성/디자인 기준을 확인한다.
2. 기존 Tool Studio dropdown trigger와 CSS, 테스트 범위를 확인한다.
3. trigger 마크업을 현재 선택값, 상위 흐름, caret 상태를 포함하도록 개선한다.
4. CSS로 안정적인 grid, ellipsis, open-state caret, 모바일 폭을 정의한다.
5. 정적 테스트에 접근성 속성, 구조 class, CSS 회귀를 추가한다.
6. test, typecheck, check, build, build:customer, perf budget, Browser smoke를 실행한다.

# 리서치 라이브러리

이 폴더는 인터넷 조사나 외부 레퍼런스 확인 중 다음에도 참고할 가치가 있는 내용을 저장한다.

## 목적

- 좋은 자료를 대화 안에만 남기지 않는다.
- 출처, 접근일, 핵심 요약, 적용 가능성을 함께 기록한다.
- 다음 작업에서 같은 조사를 반복하지 않도록 한다.

## 기본 구조

```text
_research/
  README.ko.md
  README.en.md
  index.ko.md
  index.en.md
  topics/
```

주제별 노트는 다음 형식을 권장한다.

```text
_research/topics/<topic>/YYYY-MM-DD-<slug>.ko.md
_research/topics/<topic>/YYYY-MM-DD-<slug>.en.md
```

## 기록 기준

다음 조건 중 하나라도 맞으면 문서화한다.

- 다음 작업에서 다시 참고할 가능성이 높다.
- 플랫폼, 에이전트, 도구, 스킬 설계에 영향을 준다.
- 오픈소스 채택이나 비교 평가에 도움이 된다.
- 공식 문서, 신뢰도 높은 가이드, 좋은 사례다.
- 작업 중 중요한 판단의 근거가 된다.

## 기록 원칙

- 긴 원문을 복사하지 말고 요약한다.
- 출처 URL과 접근일을 남긴다.
- 현재성에 민감한 자료는 확인 날짜를 명시한다.
- 라이선스나 사용 조건이 중요하면 함께 기록한다.
- 적용할 작업이나 관련 프로젝트를 연결한다.

## Usage Rules

- This list is a search starting point. Re-check exact source pages before using specific claims.
- Adapt large-company examples to the current project scale.
- For Korean user review/local-market tasks, check Naver Map, Kakao Map, and Naver Blog/Search first, then cross-check against official pages.
- For paper-backed evidence, combine Semantic Scholar/OpenAlex/arXiv/Papers with Code to check influence, freshness, code, and dataset availability.
- When adding a high-quality site, update both the JSON registry and this summary.

# Research Library

This folder stores reusable findings from internet research and external reference checks.

## Purpose

- Do not leave useful research only in chat.
- Record sources, access dates, key summaries, and applicability.
- Avoid repeating the same research in future work.

## Default Structure

```text
_research/
  README.ko.md
  README.en.md
  index.ko.md
  index.en.md
  topics/
```

Recommended topic note paths:

```text
_research/topics/<topic>/YYYY-MM-DD-<slug>.ko.md
_research/topics/<topic>/YYYY-MM-DD-<slug>.en.md
```

## Capture Criteria

Document research when any of these are true:

- It is likely to be useful again.
- It affects platform, agent, tool, or skill design.
- It helps with open-source adoption or comparison.
- It is official documentation, a trusted guide, or a strong example.
- It supports an important task decision.

## Capture Rules

- Summarize instead of copying long source text.
- Record source URLs and access dates.
- Mark time-sensitive references with the date checked.
- Record license or usage constraints when relevant.
- Link related work or projects.

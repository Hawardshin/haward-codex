# 스펙: 질문/지시 품질 게이트

## 요구사항

- `REQ-WS-043`

## 문제

LLM은 prompt와 context에 민감한 확률적 출력 생성기다. 따라서 모호하거나 편향적이거나 결론을 유도하는 지시를 그대로 실행하면 유창하지만 왜곡되거나 검증하기 어려운 결과가 나올 수 있다.

## 범위

- 질문/지시 품질 원칙을 지속 지시, 운영 모델, prompt router, workflow, prompt, memory bootstrap에 연결
- `ai-usage-gap-profile.json`의 나쁜 지시 패턴과 instruction rewrite contract를 공통 기준으로 사용
- 요구사항, 웹 검색 기록, 리서치 노트, 계획, 평가, 히스토리 기록

## 비범위

- 별도 prompt scoring UI 구현
- LLM 내부 확률 분포를 직접 측정하는 도구 구현
- 모든 사용자 지시를 멈추고 질문만 하는 방식으로 변경

## 수용 기준

- 모호함, 편향, 결론 유도, 출력 계약 누락, 결정론적 진실 기계 가정을 실행 전 감지하고 재작성하는 규칙이 문서화된다.
- 재작성된 task brief는 목표, 맥락, 제약, 출력 형식, 성공 기준, 반대 근거, 검증 경로를 포함한다.
- 운영 문서와 설정에서 이 규칙을 미래 세션이 찾을 수 있다.
- 외부 근거와 내부 변경 근거가 traceability와 평가에 연결된다.

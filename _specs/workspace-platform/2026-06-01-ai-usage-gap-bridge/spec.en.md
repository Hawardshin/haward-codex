# Spec: AI Usage Gap And Bridge

## Requirement

- `REQ-WS-042`

## Problem

Weak AI users often lack clear goals, context, verification, iteration, and durable asset habits. The platform should treat this as an improvable work-system problem rather than a personal flaw.

## Scope

- Add an AI usage gap diagnostic profile.
- Connect operating model, workflow, prompt, router, and index.
- Register a memory bootstrap anchor.
- Record requirements, web search records, research notes, history, and evaluation.

## Non-Scope

- Building a separate UI or training course.
- Installing external AI training platforms.
- Adding a new runtime adapter.

## Acceptance Criteria

- `ai-usage-gap-profile.json` includes gap patterns, strong user behaviors, bridge interventions, and an agent response contract.
- The workflow and prompt can run gap classification plus bridge intervention during work.
- Memory bootstrap and the operations index expose the profile.
- External factual claims are linked to grounding and web search records.

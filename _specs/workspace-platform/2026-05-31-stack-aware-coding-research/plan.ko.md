# 계획: 스택별 코딩 조사

1. 웹 검색으로 공식 문서/표준과 커뮤니티 신호 해석 근거를 확인한다.
2. `coding-research-agent` 입력 모델과 readiness check를 확장한다.
3. 템플릿, coding research profile, 문서, 프롬프트, 워크플로를 갱신한다.
4. 요구사항 기준선, 변경/검토 기록, 리서치 노트, 히스토리를 갱신한다.
5. 단위 테스트, CLI readiness check, config/memory/evaluator 검증을 실행한다.
6. 커밋하고 `origin/main`에 push한다.

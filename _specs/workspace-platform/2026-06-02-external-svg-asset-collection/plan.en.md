# External SVG Asset Collection Plan

## Work Mode

- `governance`

## Plan

1. Use web search and official repository checks to verify source and license candidates.
2. Confirm GitHub default branches and resolved commits.
3. Write a self-documenting collection policy.
4. Write a collector based on pinned archives and path allowlists.
5. Run dry-run to verify source counts and sample paths.
6. Generate actual SVG files, `LICENSE`, `SOURCE.json`, and the external registry.
7. Extend `asset_browser.py` for external registries and generate the gallery.
8. Update docs, requirements, specs, history, and evaluation records.
9. Run tests, config contract, memory bootstrap, workspace health, and browser smoke.
10. Commit and push.

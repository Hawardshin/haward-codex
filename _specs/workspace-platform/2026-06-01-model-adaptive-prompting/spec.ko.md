# 스펙: 모델별 프롬프팅 전략

## 범위

`REQ-WS-044`를 반영해 AI 사용 격차 운영 모델에 모델 capability별 프롬프팅 전략을 추가한다.

## 요구사항

- 약한/비추론/불확실 모델은 고분산 작업에서 2-pass 또는 초안-비평-수정 loop를 사용할 수 있어야 한다.
- 강한/추론 모델은 중복 호출보다 명확한 목표, 맥락, 제약, 성공 기준, 검증을 우선해야 한다.
- 반복 호출의 일치 결과는 사실 증명이 아니라 agreement signal로만 취급해야 한다.
- 설정 파일, 운영 모델 문서, workflow, prompt, 지속 지시, 메모리 부트스트랩이 같은 규칙을 가리켜야 한다.

## 제외

- 특정 벤더 모델의 성능 순위를 저장하지 않는다.
- 모든 작업에 2-pass를 강제하지 않는다.
- 새 런타임이나 API 호출 코드는 만들지 않는다.

## 성공 기준

- `ai-usage-gap-profile.json`이 자기 설명 config contract를 통과한다.
- 모델별 전략과 2-pass 조건이 한영 문서와 운영 workflow에 반영된다.
- 웹 검색 기록, 요구사항 변경/검토, 작업 히스토리, 평가 파일이 연결된다.

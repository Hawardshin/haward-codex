# Spec: Human-Like Web Search

## Goal

Promote web search from simple keyword search to an iterative research structure using query ladders, source lanes, snowballing, and selective summary capture.

## Scope

- Add `human-search-profile.json`
- Connect web-first workflow and prompt router
- Add a query-plan command to source collector
- Link requirements, history, and evaluation

## Requirement

- `REQ-WS-041`

## Out Of Scope

- Real search provider API adapters
- Automated web crawling
- Automated long-form report writing

# 계획: 전체 워크스페이스 완성도 감사

1. 웹 검색으로 프로젝트 건강도, 모노레포 구조, 작업 추적, tracing 기준을 확인한다.
2. memory bootstrap과 git 상태를 확인한다.
3. 기존 테스트와 audit를 실행해 실제 실패를 찾는다.
4. 실패한 structure audit false positive를 수정한다.
5. `workspace-health` 범위를 최신 핵심 검증으로 확장한다.
6. 오래된 미완 신호를 정리한다.
7. health report, 요구사항, 스펙, 히스토리, 평가를 남긴다.
8. 전체 검증, 커밋, push를 수행한다.

# 고품질 데이터 축적 원칙 계획

## 선택 모드

- 선택: `governance`
- 이유: 플랫폼 철학과 정체성 문서, 철학 traceability registry를 바꾸는 durable cross-workspace 변경이다.

## 실행 순서

1. 웹 검색으로 데이터 품질과 provenance 관련 공신력 있는 기준을 확인한다.
2. 운영 철학에 고품질 데이터 축적 원칙을 추가한다.
3. 플랫폼 아이덴티티 문서에 고품질 데이터 축적 시스템 정체성을 추가한다.
4. 철학 traceability registry에 새 원칙을 연결한다.
5. 플랫폼 철학 발표 스크립트와 deck spec/HTML에 같은 메시지를 반영한다.
6. 관련 검증, grounding, omission, evaluator를 실행한다.

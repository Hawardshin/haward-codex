# Agent Platform UX/Design Improvement Spec

## Related Requirement

- `REQ-WS-077`

## Scope

- Improve the `workspace-monitor` overview around a command center.
- Redesign the `platform-desktop-app` user-flow map as an installable product UX structure.
- Preserve deep-research and implementation evidence under `_research`, `_history`, `_requirements`, and `_specs`.

## Acceptance Criteria

- The first view exposes current status, attention items, next actions, evidence trail, and view/language mode.
- Metrics remain available without dominating the first-viewport message.
- Blockers and next actions provide navigation to the agents tab.
- Evidence trail shows web search, evaluation, requirement counts, and recent records.
- The desktop artifact shows first run, command center, decision inbox, recovery, and evidence review in one flow.
- Text and buttons do not overlap at mobile widths.

## Non-Goals

- Real desktop app runtime implementation
- New design-system package adoption
- User behavior telemetry implementation

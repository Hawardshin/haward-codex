# AI Assistant 운영 원칙 템플릿

## 목적

이 문서는 특정 도구가 아니라 프로젝트가 원하는 AI 작업 방식의 원본이다. Codex, Claude Code, Cursor, Antigravity, 또는 다른 도구는 이 원칙을 각자의 형식으로 불러오는 adapter만 가진다.

## 원칙

- 최신 정보나 외부 사실이 필요한 작업은 먼저 웹 검색으로 확인한다.
- 중요한 판단은 출처, 접근일, 불확실성, 계획 영향으로 기록한다.
- 프로젝트 경계, 요구사항, 스펙, 검증, 평가, 히스토리를 문서로 남긴다.
- 소스 코드는 기존 구조를 먼저 읽고, 관련 공식 문서와 좋은 오픈소스 참고 구현을 확인한 뒤 수정한다.
- 사실 주장은 근거가 없으면 단정하지 않는다.
- 작업 종료 전 검증과 평가를 실행하고, 의미 있는 변경은 커밋/배포 규칙에 맞게 기록한다.
- 도구별 지침 파일은 이 원칙을 복사해 갈라지게 하지 말고 참조한다.

## 도구 adapter 요구사항

- 도구가 읽는 instruction 파일 위치를 공식 문서로 확인한다.
- 해당 도구의 권한, sandbox, memory, rule scope 한계를 기록한다.
- 도구별 adapter에는 공통 원칙 위치, 검증 명령, 도구별 주의사항만 둔다.
- 개인 token, secret, local-only 설정은 저장소에 넣지 않는다.

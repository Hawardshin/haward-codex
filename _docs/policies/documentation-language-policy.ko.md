# 문서 언어 정책

## 목적

이 저장소는 사용자가 장기적으로 직접 읽고 추적해야 하므로 문서는 한국어를 기본으로 작성한다. 동시에 에이전트 실행 프롬프트는 토큰을 아끼고 일관된 실행을 위해 영어로 작성한다.

## 기본 규칙

- 사용자 추적용 문서, 히스토리, 운영 설명은 한국어를 기본으로 한다.
- 실제로 에이전트가 실행할 프롬프트 본문은 영어로 작성한다.
- 중요한 운영 정책, 워크플로, 프로젝트 설명은 한국어 문서와 영어 문서를 병렬로 만든다.
- 병렬 문서는 같은 폴더에 `name.ko.md`, `name.en.md` 형식으로 둔다.
- 한 문서 안에 프롬프트가 포함될 경우, 설명은 한국어로 쓰고 `Prompt` 코드 블록은 영어로 쓴다.

## 병렬 문서가 필요한 경우

- 저장소 운영 규칙
- 지속 지시
- 작업 히스토리 요약
- 프로젝트 비전과 구조
- 평가 규칙과 워크플로
- 반복 사용할 템플릿 설명

## 병렬 문서가 꼭 필요하지 않은 경우

- 코드 주석
- 짧은 설정 파일
- 일회성 임시 메모
- 프롬프트 자체만 담긴 최소 실행 파일

## 업데이트 규칙

한국어 문서와 영어 문서가 함께 있는 경우 둘 중 하나를 수정하면 다른 하나도 같은 변경 단위에서 맞춘다.

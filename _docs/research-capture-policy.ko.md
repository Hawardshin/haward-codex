# 리서치 캡처 정책

## 목적

인터넷 조사나 외부 레퍼런스 확인에서 좋은 내용을 발견하면, 다음 작업에서도 사용할 수 있도록 저장소 문서로 남긴다.

## 언제 캡처할까

- 공식 문서나 권위 있는 레퍼런스를 확인했다.
- 오픈소스 도구, 라이브러리, 프레임워크를 비교했다.
- 특정 설계 판단에 영향을 준 자료를 찾았다.
- 다음에도 반복해서 참고할 가능성이 높다.
- 평가 에이전트의 `references_checked`에 넣을 만큼 의미 있는 자료다.

## 어디에 저장할까

- 재사용 가능한 조사 결과: `_research/topics/<topic>/`
- 조사 정책과 규칙: `_docs/`
- 작업별 평가 근거: `_history/evaluations/YYYY/`
- 프로젝트에 직접 필요한 요약: 해당 프로젝트의 `docs/`

## 어떻게 기록할까

리서치 노트에는 최소한 다음을 포함한다.

- 제목
- 조사 목적
- 접근일
- 출처 URL
- 핵심 요약
- 신뢰도 판단
- 적용 가능성
- 관련 프로젝트나 작업
- 다음에 확인할 사항

## 주의할 점

- 원문을 길게 복사하지 않는다.
- 저작권이 있는 글은 짧은 인용만 사용하고 나머지는 요약한다.
- 최신성이 중요한 정보는 조사 날짜를 명확히 남긴다.
- 사용 조건, 라이선스, 보안 위험이 있으면 함께 기록한다.
- 미래 작업에서 검증할 수 있도록 불확실성, 오래될 가능성, 반대 신호도 기록한다.

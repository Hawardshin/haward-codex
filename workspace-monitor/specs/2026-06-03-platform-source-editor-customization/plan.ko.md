# 계획: 플랫폼 소스 에디터 커스터마이징

1. 공식 Monaco 자료를 확인해 기존 엔진을 유지할지 판단한다.
2. 현재 Source Review 구현과 CSS 레이아웃을 확인한다.
3. 템플릿, 경로 기반 프로필, 패치 컨텍스트 복사, Monaco theme/options를 추가한다.
4. 데스크톱식 컨트롤 바와 responsive CSS를 추가한다.
5. 요구사항, 스펙, 히스토리, 평가 기록을 남긴다.
6. 타입 검사, 빌드, 성능 예산, 테스트, 브라우저 smoke를 실행한다.
7. 커밋하고 `origin/main`에 push한다.

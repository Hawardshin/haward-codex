# Plan: Subtle Cute UI Tone

## 작업 모드

- 선택: `governance`
- 이유: 사용자 선호가 future UI 작업에 영향을 주는 지속 규칙이고, 공통 요구사항과 운영 문서를 바꾼다.
- override: 없음
- enforcement: web-first intake, memory bootstrap, 요구사항/스펙, 누락 점검, grounding, 평가를 실행한다.

## 근거

- Apple HIG Motion: motion은 status/feedback에 도움되지만 목적 없는 animation은 피해야 한다.
- Fluent 2: focus, 낮은 clutter, trust, personality를 균형 있게 다룬다.
- Material motion: motion은 관계, action availability, outcome을 알려주는 도구다.
- Don Norman emotional design: 즐거움은 사용성과 분리되지 않지만, 이 프로젝트에서는 운영 신뢰를 우선한다.

## 단계

1. 지속 지시, 공통 요구사항, UI tone policy를 갱신한다.
2. Workspace Monitor 요구사항과 README를 갱신한다.
3. CSS에서 작은 accent, hover feedback, reduced-motion 대응을 추가한다.
4. snapshot/build와 문서/평가 검증을 실행한다.

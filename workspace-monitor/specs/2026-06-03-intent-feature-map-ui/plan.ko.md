# 계획: Intent Feature Map UI

## 구현 순서

1. collector에 `collectIntentFeatureMap`을 추가해 Markdown 표를 구조화한다.
2. `WorkspaceSnapshot` 타입과 customer snapshot redaction을 갱신한다.
3. view mode와 mode/function section catalog에 `intent` 섹션을 추가한다.
4. Monitor UI에 Overview 패널과 `Intent Map` 탭을 추가한다.
5. CSS와 responsive layout을 보강한다.
6. collector/test/check/build/customer snapshot 검증을 실행한다.

## 근거

- 사용자 의도 정리 결과의 다음 우선순위가 `Intent Feature Map UI`였다.
- 외부 참고 자료는 roadmap을 Now/Next/Later 같은 이해 가능한 priority surface로 보여주는 방식을 확인하는 데만 사용했다.

Python-first structure

Agent Platform Structure

Python 코어, 오픈소스 어댑터 경계, 히스토리 기록, HTML 산출물을 분리해 장기 운영 가능한 플랫폼 구조로 시작한다.

Core Models

AgentSpec, ExecutionRequest, ExecutionResult가 플랫폼 내부 계약을 고정한다.

Runtime Boundary

AgentRuntime 뒤에 Python 함수, 외부 프레임워크, 도구 실행기를 붙인다.

OSS Evaluation

오픈소스 후보는 유지보수, 문서, 커뮤니티, 적합도, 잠금 위험을 점수화한다.

Durable Context

중요한 지시, 결정, 작업 로그는 문서와 _history/에 남긴다.

1. Define

에이전트 목적과 실행 조건을 선언한다.

2. Evaluate

직접 구현 전에 오픈소스 후보를 검토한다.

3. Adapt

외부 런타임은 로컬 인터페이스 뒤에 둔다.

4. Verify

표준 테스트와 산출물 확인을 실행한다.

5. Record

히스토리, 커밋, push까지 한 단위로 끝낸다.

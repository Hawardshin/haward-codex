# Platform Vision

## Product Direction

Build a personal platform for creating and operating agents.

The platform should eventually help with:

- defining agent roles and rules
- creating reusable skills
- creating reusable tools
- tracking work history
- compressing long-running context into durable documents
- producing Markdown and HTML artifacts
- evaluating agent outputs

## Near-Term Priorities

1. Keep the workspace organized as a monorepo.
2. Establish a repeatable history and documentation process.
3. Create reusable templates for projects and artifacts.
4. Promote repeated workflows into tools or skills.
5. Start implementation only when the operating model is clear enough.

## Open Questions

- What is the first concrete agent type to build?
- Which platform interface should come first: CLI, local web app, or document-driven workflow?
- Which work history views should be generated as HTML?

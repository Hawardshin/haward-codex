# 사용성/AI 활용 설정

이 폴더는 사용자가 AI를 더 잘 활용하도록 돕는 진단, 코칭, 반복 개선 설정을 둔다.

## 파일

- `ai-usage-gap-profile.json`: AI를 잘 쓰는 사람과 잘 못 쓰는 사람의 차이를 작업 방식, 질문/지시 품질, 검증, 반복, 자산화, 적절한 신뢰 관점에서 진단하고 간극을 줄이는 profile

## 사용 규칙

- 사용자의 요청이 모호하거나 AI 활용 자체를 개선하려는 요청이면 이 profile을 확인한다.
- 문제를 개인의 능력 부족으로 표현하지 않고, 작업 구조/맥락/검증/반복/도구화/학습 루프의 gap으로 분류한다.
- 편향적이거나 결론을 유도하는 지시는 실행 전에 중립적인 task brief로 재작성한다.
- LLM은 prompt와 context에 조건화된 확률적 출력을 생성한다는 전제로, 질문에 목표/맥락/제약/출력 형식/검증 경로를 붙인다.
- 약한/비추론/불확실 모델은 고분산 작업에서 2-pass 비교나 초안-비평-수정 loop를 검토하고, 추론/강한 모델은 중복 호출보다 task framing과 검증을 우선한다.
- 반복 호출 결과가 일치해도 사실 증명이 아니므로 별도 근거와 검증을 둔다.
- 반복되는 좋은 AI 사용 패턴은 프롬프트, 워크플로, 템플릿, 도구, 스킬, 설정으로 승격한다.
- 사실 주장, 수치, 기술 판단, 의사결정은 근거와 검증 경로를 함께 둔다.
- 설정을 바꾼 뒤 `check-config-contract`로 자기 설명성을 확인한다.

# 사용자 요청 요약

이 폴더는 사용자가 요청한 내용의 요약을 저장한다. 원문 프롬프트 전체를 보존하기 위한 위치가 아니라, 나중에 "무엇을 요청했고 어떤 구조로 반영됐는지" 빠르게 찾기 위한 요청 인덱스다.

## 목적

- 사용자 요청을 채팅 기억에만 두지 않는다.
- 원문 전체 대신 의미 요약, 의도, 지속 규칙 여부, 결과 위치를 기록한다.
- 같은 요청을 반복해서 다시 설명하지 않도록 만든다.
- 미래 에이전트가 사용자의 누적 의도와 운영 선호를 문서 기반으로 확인하게 한다.

## 경로 규칙

```text
_history/user-requests/YYYY/YYYY-MM-DD.ko.md
_history/user-requests/YYYY/YYYY-MM-DD.en.md
```

## 기록 기준

- 명시적 요청, 지속 규칙, 선호, 제약, 운영 방식 변경을 기록한다.
- 짧은 상태 확인이나 단순 대화는 의미 있는 운영 맥락이 없으면 생략할 수 있다.
- 원문 인용이 꼭 필요하지 않으면 요약만 남긴다.
- 민감 정보, 내부 추론 원문, 불필요한 중간 로그는 저장하지 않는다.

## 필수 필드

- 요청 순서
- 요청 요약
- 의도 유형
- 지속 규칙 여부
- 반영 위치
- 관련 계획, 평가, 작업 요약, 커밋

## 종료 평가 규칙

의미 있는 작업의 `work-evaluator-agent` 입력에는 `user_request_summary_targets`를 포함한다. 누락되면 blocking gap이다.

요청 요약이 실제 결과로 어떻게 이어졌는지는 `_history/request-traces/YYYY/`에 연결한다.

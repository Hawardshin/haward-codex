# 사용자 요청 요약

- 날짜: 2026-06-07
- 프로젝트: platform-desktop-app
- 요청: 자동 업데이트 기능 중 동작하지 않는 부분을 계속 고치고, 사용자가 반복해서 지시하지 않아도 끝까지 구현/검증.

## 요구 후보

- 앱 안에서 업데이트 채널 상태만 보는 것이 아니라 실제 업데이트 확인과 설치를 실행할 수 있어야 한다.
- TypeScript와 Rust 양쪽 구현이 컴파일되어야 한다.
- 릴리스/readiness 계약과 테스트가 새 자동 업데이트 표면을 감시해야 한다.
- 내부 빌드에서는 updater 환경 변수가 없어도 앱 전체가 실패하지 않아야 한다.

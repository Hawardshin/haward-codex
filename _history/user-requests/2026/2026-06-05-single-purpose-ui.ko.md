# 사용자 요청 요약: Single Purpose UI

## 요약

- 사용자는 화면에서 인지 가능한 정보량에 한계가 있으므로, 기능 하나가 명확히 한 가지 일만 하도록 UI를 조정하라고 요청했다.

## 해석

- Workspace Monitor 홈 화면의 복합 버튼, 중복 이동, 여러 정보를 한 번에 여는 disclosure panel을 줄인다.
- 이 원칙은 앞으로의 플랫폼 UI에도 적용될 durable instruction으로 취급한다.

## 산출물

- 단일 목적 UI 요구사항
- Workspace Monitor 홈 구현 변경
- 영속 지침, UI 정책, memory bootstrap 갱신
- 검증 및 요청 추적 기록

# 사용자 요청 요약: 소스 워크벤치 컨트롤 프리미티브

- 날짜: 2026-06-05
- 요지: 소스 작업 화면의 버튼과 선택 드롭다운이 기본 브라우저 컨트롤처럼 보여 이상하므로 고쳐 달라는 요청.
- 지속 조건: 구현 후 사용자가 직접 빌드하지 않도록 자동 빌드까지 수행.

## 해석

- 최근 소스 편집 UX 작업의 후속 수정으로 보았다.
- 핵심 범위는 파일 선택 드롭다운, 소스 작업 버튼, 편집기 툴바 버튼, 워크스페이스 탐색기 명령 버튼이다.
- 전체 앱의 모든 `<select>` 제거는 이번 요청의 직접 범위 밖으로 두었다.

# 사용자 요청 요약: 오픈소스 Agent Platform Landscape

## 요약

사용자는 현재 플랫폼의 특징을 뽑아내고, 유사한 오픈소스를 매우 많이 조사해 달라고 요청했다.

## 해석

- 로컬 플랫폼이 실제로 어떤 제품 포지션과 기능 구조를 갖는지 먼저 정리한다.
- 단순히 몇 개 경쟁 제품을 나열하지 않고, coding agent, agent framework, workflow builder, local desktop AI app, workflow orchestration, observability까지 넓게 조사한다.
- 조사 결과를 현재 플랫폼의 차별점, 참고할 구조, 다음 구현 후보로 연결한다.

## 범위

- 코드 구현 없음.
- 앱 빌드 없음. 이번 요청은 문서화/리서치이며 product source를 변경하지 않는다.
- 오픈소스 source copy, dependency install, license adoption 없음.

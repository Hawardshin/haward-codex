# User Request: Core Feature Connections

날짜: 2026-06-07

## 요약

사용자는 플랫폼의 주요 기능을 실제 작업 흐름에 연결하라고 요청했다. 이전에 구현한 기능들이 각자 떨어져 보이지 않도록, 홈에서 에이전트, 툴, 실행, 평가, 파일, 가시성으로 바로 이동할 수 있어야 한다.

## 해석

- 단순 안내 문구가 아니라 클릭 가능한 기능 연결을 구현한다.
- 연결은 섹션 이동뿐 아니라 해당 작업 의도와 단계 선택까지 포함한다.
- UI/UX는 직관적이고 기존 workbench 구조와 일관되어야 한다.

# 사용자 요청 요약: AgentCore와 유사하게

## 요약

- 사용자는 현재 데스크톱 에이전트 UI가 AgentCore와 더 유사한 플랫폼 구조를 갖추길 요청했다.
- 직전 capability bundle에서 한 단계 더 나아가, 선택된 능력이 어떤 AgentCore식 리소스와 실행 생명주기로 연결되는지 화면에서 명확히 보여주는 개선으로 범위를 잡았다.

## 범위

- Workspace Monitor Agents 화면의 AgentCore Quick Builder
- capability selection 이후 resource topology/lifecycle preview

## 제외

- 실제 AWS AgentCore 배포
- connector credential 발급
- 외부 cloud resource provisioning

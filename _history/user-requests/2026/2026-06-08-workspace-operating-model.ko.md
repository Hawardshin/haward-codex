# User Request Summary

## 요약

사용자는 데스크톱 앱의 목적을 명확히 다시 정의했다. 앱은 Codex, Cursor, Claude Code, Antigravity 같은 도구 자체가 무엇이든 상관없이 여러 Git 프로젝트를 쉽게 가져오고, 현재 작업의 순서, 문서, 근거, 보고서를 보여주는 프로젝트 관리 앱이어야 한다. 각 프로젝트는 별도 Git 저장소로 분리되어야 하며, 이 루트 저장소 안에 프로젝트 소스가 섞이면 안 된다.

## 핵심 요구

- 모든 durable 프로젝트는 별도 Git 저장소 또는 submodule/imported repo로 관리.
- 사용자 부재 시 전체 작업을 멈추지 않고 중요한 결정만 보류.
- 결정 보류 항목은 대화/결정함에서 나중에 재개 가능하게 표시.
- 초보자도 자연어 작업 요청만으로 전문가와 같은 산출물 계약에 도달.
- 에이전트 제작, 툴 관리, Ollama, 직접 공급자 실행은 별도 데스크톱 앱으로 분리.
- 작업 순서, 기획 문서, 근거, 보고서 확인이 기본 UX.

## 이번 slice 결과

운영 모델 registry, 스냅샷 `operatingModel`, 프로젝트 관리 UI 패널, 테스트, Git 분리 검증 기록을 추가했다.

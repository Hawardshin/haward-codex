# 사용자 요청 요약: 단일 주 기능 화면 공간 원칙

## 요약

사용자는 현재 화면이 좋지 않다고 평가하며, 화면에 주 기능이 하나라면 그 기능이 화면을 다 채우는 것을 기본 원칙으로 삼으라고 요청했다.

## 분류

- request_type: durable_instruction
- work_mode: governance
- affected_area: platform UI principles, persistent instructions, UI policy

## 해석

- 이 지시는 특정 화면 하나에 대한 일회성 취향이 아니라 앞으로의 UI 설계 기준이다.
- 실제 구현 대상 화면은 지정되지 않았으므로 이번 작업은 원칙 반영과 추적 기록에 한정한다.

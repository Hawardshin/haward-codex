# 사용자 요청 요약

사용자는 현재 데스크톱 플랫폼이 여전히 웹 UI처럼 보이고 기능이 UI에 충분히 녹지 않는다고 지적했다. 이번 요청에서는 더 추가할 만한 기능을 UI에 잘 통합하고, IntelliJ 디자인을 참고해 데스크톱 앱답게 구성하라고 요구했다.

## 요구 후보

- 실행 기능을 한 화면의 긴 스크롤이 아니라 IDE식 실행 표면으로 구성한다.
- IntelliJ의 tool window, Services, Problems, Run Configuration 같은 장점을 참고한다.
- 검색 에이전트, CLI 세션, 다중 CLI, 모델/provider, readiness 문제를 사용자가 바로 이해하고 클릭할 수 있게 한다.
- 다크/라이트 테마와 반응형에서 깨지지 않게 한다.

# 2026-06-07 다크모드 색상 일관성 UI 개선 요청

## 요청 요약

- 사용자는 데스크톱 Workspace Monitor에서 다크모드일 때 색상 일관성이 깨지는 UI 문제 개선을 요청했다.
- 작업 범위는 `platform-desktop-app/renderer/workspace-monitor`의 다크 테마 토큰, 시스템 다크와 명시 다크의 일관성, 실제 렌더 배경 불일치 확인과 회귀 테스트 추가로 한정했다.

## 수용 기준

- 명시 다크(`theme-dark`)와 시스템 다크(`theme-system` + OS 다크)가 같은 핵심 색상 토큰을 사용한다.
- 다크모드 기본 텍스트와 포커스 링이 과한 순백색으로 튀지 않는다.
- 앱 루트 바깥 `body` 배경도 다크 렌더 상태와 일치해 초기 렌더나 오버스크롤에서 라이트 배경이 드러나지 않는다.
- 색상 대비 테스트, 타입/계약 체크, 내부 데스크톱 패키징이 통과한다.

# User Request: Runtime Setup Check

## 요약

사용자는 터미널 설정이나 자동 CLI 설정이 되어도 실제로 되었는지 확인하는 기능이 없으니 추가해 달라고 요청했다.

## 해석한 요구

- 설정 화면에서 selected CLI adapter와 terminal shell 설정을 바로 점검할 수 있어야 한다.
- CLI 설치/로그인 자동화가 아니라 현재 설치형 런타임 기준의 실행 가능 여부를 보여줘야 한다.
- 점검 결과는 사용자가 어디가 막혔는지 볼 수 있어야 한다.

## 소유 프로젝트

- `platform-desktop-app`

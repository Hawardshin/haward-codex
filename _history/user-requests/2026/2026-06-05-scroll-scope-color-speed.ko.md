# 사용자 요청 요약: Scroll Scope Color Speed

## 요약

- 사용자는 스크롤을 범위별로 나눠서 할 수 있게 하고, 색상을 깔끔하고 단정하지만 세련되게 적용하며, 속도도 개선하길 요청했다.

## 해석한 완료 기준

- 주요 작업면과 내부 목록/터미널/소스/Tool Studio 영역이 서로 독립된 scroll scope를 가진다.
- 스크롤 가능한 영역은 시각적으로 과하지 않은 scrollbar color와 경계로 식별된다.
- 화면 밖 3D animation은 pause되어 스크롤/버튼 반응을 방해하지 않는다.

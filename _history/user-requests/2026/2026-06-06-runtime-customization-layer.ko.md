# User Request: Runtime Customization Layer

## 요약

사용자는 실제 사용을 위해 provider, 모델, API 주소, 터미널, 명령 등 실행 설정이 전부 커스텀 가능해야 하며, 단순 표시가 아니라 사용성이 높아져야 한다고 요청했다.

## 해석한 요구

- 설정 UI에서 선택/입력 가능한 커스텀 항목을 늘린다.
- 커스텀 값이 실제 데스크톱 앱 실행 경로에 반영되게 한다.
- 기본 버튼/드롭다운 느낌을 피하고 기존 앱 스타일의 카드/버튼/입력으로 구성한다.
- 구현 후 빌드까지 자동으로 실행한다.

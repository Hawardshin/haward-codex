# 사용자 요청 요약: desktop project management sliced implementation

- 날짜: 2026-06-08
- 요약: 사용자는 데스크톱 앱을 Ollama/툴/에이전트 관리보다 Git 프로젝트 관리 플랫폼으로 재정의하고, 기능 구현을 잘게 나누어 빠짐없이 진행하라고 요청했다.
- 핵심 요구:
  - 프로젝트 관리 기능을 slice별로 구현한다.
  - 사용자가 Git 작업공간, 현재 작업, 보고서, 근거, 작업 순서를 쉽게 볼 수 있게 한다.
  - 고급 에이전트/툴 기능은 기본 사용자 흐름에서 분리한다.
  - 터미널 실행과 보고서 확인이 프로젝트 화면에서 바로 이어져야 한다.
- 보존 정책: 전체 원문은 중복/장문이라 저장하지 않고, 구현 가능한 요구사항 후보만 요약했다.

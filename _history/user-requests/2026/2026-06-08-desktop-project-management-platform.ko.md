# 사용자 요청 요약: desktop project management platform

- 날짜: 2026-06-08
- 범위: `platform-desktop-app/`
- 원문 보존 여부: 전체 원문은 보존하지 않음

## 요약

사용자는 이미 desktop workspace tracker와 agent/tool/Ollama 운영 플랫폼이 크게 분리된 상태에서, 데스크톱 앱 쪽을 프로젝트 관리 플랫폼으로 완성하라고 요청했다. Ollama, 툴, 에이전트 관리류는 별도 플랫폼으로 두고, 데스크톱은 Git 작업공간 가져오기, 프로젝트별 작업 상태, 계획, 마일스톤, 보고서, 근거, 실행 흐름 확인에 집중해야 한다.

## 핵심 요구

- 데스크톱 앱은 프로젝트 관리/작업 추적 표면이 되어야 한다.
- Ollama/툴/에이전트 운영은 기본 사용자 UI에서 뒤로 빠져야 한다.
- 사용자가 Git 프로젝트를 가져오고 현재 작업 상태를 쉽게 볼 수 있어야 한다.
- 보고서와 근거 확인이 프로젝트 흐름 안에 있어야 한다.

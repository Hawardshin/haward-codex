# 사용자 요청 요약: Text Wrapping Contract

## 요약

- 사용자는 Workspace Monitor UI에서 텍스트가 줄바꿈으로 이상해지거나 깨지는 현상을 없애길 요청했다.
- 특히 한 화면에 많은 정보를 담는 과정에서 텍스트가 어색하게 끊기고 비전체화면에서 레이아웃이 망가지는 문제를 줄여야 한다.

## 해석한 완료 기준

- 문장형 텍스트와 버튼 라벨은 작은 화면에서도 읽기 좋은 줄바꿈을 유지한다.
- 경로, 명령, 코드처럼 긴 토큰은 레이아웃을 가로로 밀지 않는다.
- 변경은 static regression test와 desktop/mobile smoke로 검증된다.

# 사용자 요청 요약: 쉬운 AI 로그인 설정

- 날짜: 2026-06-06
- 대상: `platform-desktop-app`
- 요약: 사용자가 AI provider 설정 기능을 더 늘리고, 로그인/계정 설정을 쉽게 할 수 있도록 데스크톱 앱 설정 화면 개선을 요청했다.
- 해석: 공식 provider 로그인/콘솔 링크, API key 발급/저장, 연결 상태, 모델 확인, 작업 기본값 선택을 한 설정 흐름으로 묶는다.
- 제외: 민감한 key 원문을 읽거나 기록하지 않는다. 비공식 웹 세션 cookie 기반 로그인을 구현하지 않는다.

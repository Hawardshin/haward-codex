# 사용자 요청 요약: 미뤄둔 구현 큐 폐쇄

- 날짜: 2026-06-08

## 요약

사용자는 앞서 분리한 두 데스크톱 앱과 Git repository 구조에서 미뤄둔 구현을 모두 이어서 완료하라고 요청했다. 핵심은 프로젝트 관리 앱을 사용자가 쉽게 쓰는 작업 추적/문서/근거 중심 플랫폼으로 만들고, agent/tool/Ollama/provider 관리 기능은 별도 데스크톱 앱으로 분리해 실제 실행면을 갖추는 것이다.

## 유지해야 하는 기준

- 작업은 사용자가 하나씩 설정하지 않아도 쉽게 시작할 수 있어야 한다.
- 각 프로젝트는 독립 Git repository로 관리되어야 한다.
- 작업 히스토리와 근거는 프로젝트/ledger 관점에서 추적 가능해야 한다.
- public release 준비가 되지 않은 항목은 완료처럼 보이게 하지 않는다.

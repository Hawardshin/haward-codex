# 사용자 요청 요약: 툴 배포하는 화면

## 요약

- 사용자는 Tool Studio에서 툴을 배포하는 화면 자체를 더 명확하고 실사용 가능한 작업면으로 개선하길 요청했다.

## 범위

- Workspace Monitor Tool Studio `deploy` mode
- 배포 target 선택, release/preflight/auth/observability/rollback preview, 주요 액션 분리

## 제외

- 실제 cloud 배포 실행
- credential provider 생성
- registry 파일 직접 변경

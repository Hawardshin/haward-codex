# 사용자 요청 요약: Native Select 교체

날짜: 2026-06-06

## 요약

사용자는 macOS 기본 드롭다운처럼 보이는 선택 버튼이 앱 UI와 맞지 않고 예쁘지 않다고 지적했다. Provider 선택처럼 보이는 OS 기본 팝업을 포함해, 기본 버튼/드롭다운 느낌을 제거하고 앱 스타일 선택 컨트롤로 개선하기를 요구했다.

## 수용 기준

- native `<select>` 팝업을 주요 화면에서 제거한다.
- 선택지는 사용자가 바로 이해할 수 있는 버튼 또는 앱 스타일 메뉴로 제공한다.
- 버튼은 음영, 선택 상태, hover 상태가 구분되어야 한다.
- 구현 후 테스트와 내부 빌드까지 자동 실행한다.

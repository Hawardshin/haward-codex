# 사용자 요청 요약: VS Code 하드 포크 워크스페이스

날짜: 2026-06-06

## 요약

사용자는 `microsoft/vscode`를 클론하고, VS Code 소스와 기능을 최대한 활용하면서 새로운 하드 포크성 작업을 시작하라고 요청했다. 현재 작업이 작업 공간적 성격을 잃고 있으므로, VS Code 소스를 직접 변경하며 워크스페이스 기능을 완전히 녹이는 방향을 원했다.

## 실행 계약

- 계획만 세우지 않고 실제 clone, 설치, 소스 변경, 빌드 검증을 수행한다.
- 전체 완성은 여러 slice가 필요하지만, 첫 slice는 실제로 동작하고 이어 작업 가능한 기준선이어야 한다.
- 설치나 native/runtime 준비가 필요하면 기록과 rollback을 남기고 수행한다.

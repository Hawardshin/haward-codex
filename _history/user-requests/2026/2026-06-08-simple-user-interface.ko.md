# 사용자 요청 요약: 기본 사용자 인터페이스 단순화

## 요약

사용자는 플랫폼 사용법이 너무 복잡하고 커스텀 기능이 전면에 있어 첫 실행과 기본 사용이 어렵다고 말했다. 커스텀/고급 기능은 뒤에서 자동화되거나 고급 보기로 숨기고, 사용자는 쉬운 인터페이스만 보게 화면 구성을 전반적으로 바꾸라고 요청했다.

## 요구 후보

- 기본 view mode는 사용자 보기여야 한다.
- 첫 화면은 작업 요청 입력과 실행 시작 중심이어야 한다.
- 커스텀 에이전트, 툴, 소스, 운영 기능은 기본 사용자 화면에서 숨겨야 한다.
- 고급 기능은 삭제하지 않고 developer/superadmin 보기에서 접근 가능해야 한다.

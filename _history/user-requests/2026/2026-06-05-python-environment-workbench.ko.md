# 사용자 요청 요약: Python 실행환경

## 요약

- Tool Studio에서 Python 실행환경을 명확한 단일 기능 화면으로 개선해 달라는 요청.

## 해석

- 기존 `파이썬 환경` 탭은 요약 정보만 있고 전용 작업면이 부족했다.
- 사용자는 venv, dependency, 실행 명령, sandbox 경계, smoke 실행을 한 화면 안에서 과밀하지 않게 확인해야 한다.

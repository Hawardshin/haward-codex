# 사용자 요청 요약: 가상 환경

## 요약

- Tool Studio에서 가상환경 관리 기능을 더 명확히 개선해 달라는 요청.

## 해석

- 기존 Python 실행환경 화면은 실행 프로필을 제공하지만, `.venv` lifecycle 자체를 다루는 전용 관리 흐름이 부족했다.
- 사용자는 생성, 활성화/직접 실행, 설치, freeze, 재생성을 명령과 evidence 기준으로 구분해야 한다.

# 사용자 요청 요약: AI EVAL cockpit

## 요약

사용자는 플랫폼 전반의 사용성/성능/UI/기능 개선을 계속 진행하고, EVAL 기능과 현재 작업 평가 보고서를 탭으로 추가하며, 히스토리/토큰 수/툴 사용을 점수 비교하고, 오픈소스 평가 기능을 참고해 적용하라고 요청했다. 캐릭터는 물개를 쓰라고 요청했다.

## 이번 반영 범위

- EVAL 탭과 보고서 UI
- 오픈소스 EVAL 후보 registry/UI
- Tool Studio 물개형 캐릭터
- 자동 build/package 검증

## 후속 범위

- 외부 EVAL runner 실제 설치/실행 통합
- token/cost/run schema 구조화
- 장기 route-level monitor shell 개선

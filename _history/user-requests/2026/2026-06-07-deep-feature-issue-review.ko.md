# 사용자 요청 요약

- 날짜: 2026-06-07
- 사용자는 데스크톱 앱 packaging 실패 이후, 기능적 이슈와 미구현 후보를 깊게 검토하고 계속 구현해 달라고 요청했다.
- 특히 자동 업데이트, Codex/init 가시성, agent 설정/사용 방법, 설정 동기화, 공통 로직 분리, Rust/TypeScript 확인, 코드 구조 분리, 주석/한국어 설명 요구가 반복되었다.
- 이번 slice는 새로 확인된 기능 이슈를 구현하고, source scan과 검증 게이트로 추가 위험 후보를 좁히는 데 집중했다.

## 수용 기준

- Rust/TypeScript compile/test가 통과해야 한다.
- 자동 업데이트 설치/restart 결과가 사용자에게 보이는 상태와 일치해야 한다.
- 설정/히스토리/snapshot 로딩 실패 후 재시도 또는 cleanup 문제가 없어야 한다.
- 변경은 공통 유틸/hook에 넣어 일관되게 동작해야 한다.
- 검토 결과와 남은 공개 배포 게이트는 기록으로 남겨야 한다.

# 2026-06-07 소스 로드 요청 훅 및 테스트 유틸 분리 요청

## 요청 요약

- 미뤄둔 구현을 계속 진행한다.
- 큰 소스 파일을 계속 줄이고 공통 로직을 일관된 모듈로 분리한다.
- 기능 이슈가 생기지 않도록 TypeScript와 Rust 패키징 흐름까지 확인한다.
- 반복 내부 실행으로 앱 인스턴스가 누적되는 리소스 이슈를 발견하면 같이 정리한다.

## 적용 범위

- 소유 프로젝트: `platform-desktop-app`
- 주요 대상: Workspace Monitor source editor 구조 분리
- 작업 모드: `standard`

## 수용 기준

- `MonitorShell.tsx` 안의 소스 로드 비동기 요청 게이트를 재사용 가능한 훅으로 분리한다.
- TypeScript 테스트에서 반복하던 TS 모듈 로딩 코드를 공통 테스트 유틸로 이동한다.
- 내부 앱 실행 스크립트는 기본적으로 기존 앱 인스턴스를 재사용해야 한다.
- 구조 계약 테스트와 내부 패키징 명령이 통과해야 한다.

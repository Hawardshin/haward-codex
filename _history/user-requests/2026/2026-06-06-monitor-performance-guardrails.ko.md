# 사용자 요청 요약: Monitor 성능 가드레일 완성

## 요약

사용자는 탭 간 이동이 여전히 느리다고 지적했고, 데스크톱 앱이므로 CPU/RAM/runtime 자원을 실제로 쓰는 방향으로 근본 성능 문제를 해결하라고 요청했다. 또한 범위가 넓다는 이유로 회피하지 말고 구현과 빌드까지 끝내라고 지시했다.

## 실행 해석

- 이전 resident/preload/lazy 작업을 전제로 한다.
- 남은 핵심은 퇴행 방지와 실제 빌드 산출물 기준 검증이다.
- public release 준비 완료가 아니라 internal package와 local 성능 감사 완료를 목표로 한다.

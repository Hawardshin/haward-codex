# 사용자 요청 요약: Native Resource Telemetry

## 요약

사용자는 이전 잔여 항목까지 “다 해”라고 지시했다. 이전 맥락은 탭 이동 지연, 데스크톱 자원 사용, Rust/Tauri 활용, 빌드 자동 실행이었다.

## 실행 해석

- 이미 구현된 lazy/resident/native cache 위에 실제 app process/system telemetry를 추가한다.
- 외부 Apple 자격증명 없이 public release를 완료했다고 주장하지 않는다.
- 구현 가능한 부분은 코드, UI, readiness, tests, build까지 수행한다.

# 2026-06-06 사용자 요청 요약

## 요약

사용자는 미뤄둔 작업을 계속 진행하라고 요청했다.

## 해석

직전 완료 기록에서 남긴 후속 작업 중 실제 runtime metric 기반 score source 연결을 우선 처리한다. 이 선택은 사용자가 반복적으로 요구한 성능 개선, desktop OS 자원 활용, EVAL 탭, build 자동화와 직접 연결된다.

## 범위

- 포함: runtime metric을 EVAL score에 연결, 계약/테스트/build/package 검증.
- 제외: 새 external EVAL runner 설치, telemetry persistence, 모든 UI 전면 리팩터링.

# Plan Evidence: Capability Idea Evaluation

| Plan Step | Evidence |
| --- | --- |
| Separate idea generation from evaluation | User request plus evaluator/reflect-refine loop references |
| Require several ideas | Prevent overbuilding the first generated idea and find lighter assets |
| Make evaluation criteria explicit | Compare repetition reduction, time savings, maintenance cost, evidence strength, risk, and smallest-asset fit |
| Record reasons for unselected ideas | Preserve why an idea was not built and make future reevaluation possible |

# Plan Evidence: Capability Idea Evaluation

| 계획 단계 | 근거 |
| --- | --- |
| 아이디어 생성과 평가를 분리한다 | 사용자 요청과 evaluator/reflect-refine loop 근거 |
| 여러 아이디어를 요구한다 | 첫 아이디어 과대 구현을 막고 더 작은 자산을 찾기 위함 |
| 평가 기준을 명시한다 | 반복 감소, 시간 절감, 유지보수 비용, 근거 강도, 위험, 작은 자산 적합성을 비교해야 함 |
| 선택하지 않은 아이디어 이유를 기록한다 | 나중에 왜 만들지 않았는지 추적하고 재평가할 수 있게 하기 위함 |

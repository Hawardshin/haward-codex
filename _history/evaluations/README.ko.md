# 작업 평가 보고서

이 폴더는 의미 있는 작업을 마무리할 때 생성한 평가 보고서를 보관한다.

## 파일 규칙

```text
_history/evaluations/YYYY/YYYY-MM-DD-<slug>.ko.md
```

중요한 지속 맥락이면 영어 companion 문서도 함께 만든다.

```text
_history/evaluations/YYYY/YYYY-MM-DD-<slug>.en.md
```

## 보고서에 포함할 내용

- 초기 지시
- 작업 요약
- 확인한 레퍼런스
- 웹 검색 기록 경로
- 변경 파일
- 검증 결과
- 평가 상태
- gap과 개선점
- follow-up action
- 재작업 결과

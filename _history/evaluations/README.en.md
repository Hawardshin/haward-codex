# Work Evaluation Reports

This folder stores evaluation reports created when meaningful work is closed.

## File Convention

```text
_history/evaluations/YYYY/YYYY-MM-DD-<slug>.ko.md
```

Create an English companion when the report is important durable context.

```text
_history/evaluations/YYYY/YYYY-MM-DD-<slug>.en.md
```

## Report Contents

- initial instruction
- work summary
- references checked
- web search record targets
- user request summary targets
- context archive targets
- changed files
- verification results
- evaluation status
- gaps and improvements
- follow-up actions
- rework result

# 작업 요약: 오픈소스 Agent Platform Landscape

- 현재 플랫폼 특징을 로컬 제품 레지스트리와 Tauri 설정에서 추출했다.
- 플랫폼을 "local Agent Workspace OS / Agent Workbench"로 볼 수 있다는 결론을 기록했다.
- coding agent, agent framework, workflow builder, local AI desktop, workflow orchestration, developer platform, observability/eval, sandbox/runtime 계열 오픈소스를 넓게 조사했다.
- 직접 참고 우선순위를 OpenHands, Goose, Cline, Aider, opencode, Codex, Gemini CLI, ClawX, Accomplish, Agentify Desktop, OpenLoaf, Dify, Langflow, Flowise, n8n, Langfuse, Phoenix, promptfoo 등으로 정리했다.
- 제품 구현 후보로 guest CLI adapter cockpit, resident workspace prewarm, Agent Factory wizard, Decision Inbox, Run Record timeline, Provider Account Center, Evaluation cockpit을 도출했다.

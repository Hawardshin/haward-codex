## 축적 데이터 보기 Surface

- `platform-desktop-app` Tauri backend에 `get_accumulated_data_overview` command와 `AccumulatedDataOverviewReport`를 추가했다.
- 누적 데이터 store는 task runs, decision inbox, support bundles, payload audits, agent workspace를 포함하며 record count, size, latest update, path, visibility, purpose, action label을 반환한다.
- directory scan은 `MAX_ACCUMULATED_DATA_SCAN_FILES`로 제한하고 symlink를 따라가지 않도록 구현했다.
- Workspace Monitor Desktop Runtime에 `Accumulated` metric, command palette의 `Accumulated data`, 전용 `축적 데이터 인덱스` 패널을 추가했다.
- installer shell runtime contract에 `accumulated_data_index` target과 `get_accumulated_data_overview` command surface를 연결했고 readiness/test가 이를 검증하게 했다.

## 축적 데이터 저장 포맷

- `get_accumulated_data_overview`가 raw scan 결과를 반환하는 데서 끝나지 않고 `app_data/runtime-data/indexes/accumulated-data-overview.v1.json` versioned manifest를 저장하게 했다.
- `AccumulatedDataOverviewReport`에 `schemaVersion`, `storageFormatVersion`, `indexPath`, `formatMigrationStatus`를 추가했다.
- Workspace Monitor Accumulated Data 패널에 manifest schema, storage format, migration status, index path를 표시했다.
- runtime contract의 `accumulated_data_index` target을 `runtime_data_index_manifest`와 `app_data/runtime-data/indexes`로 바꿨고, readiness/test/contract checks가 새 저장 포맷 토큰을 검증하게 했다.

## Desktop Workspace Host

- 앱 데이터에 `workspace-host/desktop-workspace-state.v1.json` active workspace state를 저장하는 Tauri commands를 추가했다.
- `get_desktop_workspace_state`, `set_desktop_workspace_path`, `clone_desktop_workspace`로 기존 workspace import와 bounded Git clone을 데스크톱 앱 안에서 처리하게 했다.
- source editor file listing/read/write와 CLI session/task pipe working directory가 app-selected workspace를 우선 사용하고, 없으면 개발 repo fallback을 쓰게 했다.
- Workspace Monitor Desktop Runtime에 `Workspace Host` 패널을 추가해 active workspace, managed root, state file, Git availability, import/clone controls를 표시했다.
- service readiness의 runtime workspace persistence blocker를 구현 상태에 맞게 갱신했다.

## Single Feature Full-Screen UI Principle

- 한 화면의 주 기능이 하나라면 그 기능이 화면 대부분을 차지해야 한다는 원칙을 persistent instructions, UI tone policy, `AGENTS.md`, memory bootstrap manifest에 반영했다.
- split layout, dashboard grid, side-by-side panel은 비교, monitoring, 다중 주 작업처럼 동시에 봐야 할 명확한 이유가 있을 때만 쓰도록 검증 기준을 추가했다.
- 이번 요청은 특정 화면을 지정하지 않았으므로 실제 UI 구현 변경은 비범위로 남겼다.

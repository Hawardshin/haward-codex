# 작업 요약: 2026-06-05

## Source Loading Performance

- `DesktopRuntimePanel`이 Desktop 런타임 화면에서도 source catalog scan을 자동 실행하던 경로를 Source 화면으로 제한했다.
- Source 화면에서 왼쪽 Explorer와 오른쪽 flat file browser가 같은 파일 목록을 중복 렌더링하던 구조를 제거했다.
- Source 화면 기본 view를 editor로 바꾸고, 파일 선택은 Explorer가 담당하게 했다.
- Source filter는 deferred value로 처리하고, Explorer 하위 directory는 기본 collapsed로 렌더링한다.
- 검증: `pnpm run check`, `pnpm test`, `pnpm exec next build`, `pnpm run perf:budget`, localhost smoke 통과.

## Button Target Sizing

- `globals.css`의 control token을 일반 44px, compact 40px, dense 32px 기준으로 정리하고 mobile/coarse pointer에서는 48/44/40px로 올리게 했다.
- Source/Explorer/toolbar, task pipe, search/agent, decision, segmented/chip/operator/command action 버튼에 공통 token을 적용했다.
- 검증: `pnpm run check`, `pnpm test`, `pnpm exec next build`, `pnpm run perf:budget`, localhost HTTP smoke, in-app Browser 첫 화면 size audit 통과.

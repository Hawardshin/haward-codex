## Typography Scale

- Workspace Monitor의 텍스트 크기가 화면마다 들쭉날쭉하지 않도록 `globals.css`에 역할 기반 typography token을 추가했다.
- 직접 숫자 기반 `font-size` 선언을 token 참조로 바꾸고, 앱 내부 `<small>` 기본 축소를 막아 visible text가 11px 미만으로 내려가지 않게 했다.

- dark theme, rail, primary action, active tab, code/source/terminal dark surface의 foreground를 흰색 token으로 통일했다.
- 검증: CSS font-size/font-family/dark foreground token audit, 정적 export Playwright 5섹션 x 5viewport typography/dark foreground audit, workspace-monitor check/test/build:customer/perf, platform-desktop-app check 통과.

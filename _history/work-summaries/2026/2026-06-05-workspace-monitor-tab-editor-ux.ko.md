# 작업 요약: Workspace Monitor 탭 전환과 소스 편집 UX

- `MonitorShell.tsx`에서 섹션 전환을 첫 페인트 이후로 미루던 상태와 ref를 제거했다.
- Monaco와 에이전트 3D scene 모듈을 idle 시간에 선로딩하도록 추가했다.
- 소스 편집 패널을 숨김 상태에서도 마운트 유지하고, 숨겨진 상태에서 런타임 실행 요청과 세션 폴링을 처리하지 않도록 `surfaceActive`를 추가했다.
- 사이드바 확장 폭과 터미널 오프셋을 조정했다.
- Monaco 기본값을 줄바꿈 켬, 미니맵 끔, 글꼴 13px, 더 큰 편집 높이로 바꾸고 편집기 바로 위 주요 액션을 추가했다.
- 정적 테스트와 CSS 감사 스크립트를 새 레이아웃 계약에 맞게 갱신했다.

## 검증

- 테스트, 체크, 고객용 렌더러 빌드, 브라우저 스모크 통과.

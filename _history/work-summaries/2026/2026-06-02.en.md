## Non-Blocking Clarification

- Request: The user pointed out that AI stopping every task while waiting for one answer is a major bottleneck.
- Result: Added `REQ-WS-047` and updated platform rules so pending answers isolate only `blocked_decision` items while safe independent work continues as `unblocked_work`.
- Core rule: Do not pause the whole task. Pause only what cannot be decided without the answer, and record assumptions plus `resume_action` for later correction.

## Human Decision Inbox

- Request: The user asked for a structure that collects human-needed issues at once, interrupts/resumes when the human returns, and keeps other work moving while waiting.
- Result: Added `REQ-WS-048` and created `_ops/coordination/human-decision-inbox.json` as the central inbox.
- Core rule: Questions become inbox records instead of loose chat. While waiting, `unblocked_work` continues. When an answer arrives, current work is checkpointed first, then the agent chooses immediate resume or next-safe-point resume by priority and risk.

## Install Mode Split

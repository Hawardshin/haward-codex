# 작업 요약: 자율 넓은 구현 기본값

- 루트 `AGENTS.md`에 후속 구현 명령을 넓은 자율 multi-slice 구현 루프로 해석하는 규칙을 추가했다.
- 지속 지시 원본, 한국어 문서, 영어 문서에 같은 운영 규칙을 반영했다.
- 메모리 부트스트랩 manifest의 persistent instruction 설명과 update trigger에 새 정책을 추가했다.
- 기록 파일을 만들어 요청, 웹 검색, 계획, 근거, 누락 점검, 평가, trace, timing을 연결했다.

## 향후 기대 동작

사용자가 `계속 구현`, `이어서 구현`, `부족한 부분 구현`, `넓게 구현` 같은 후속 명령을 보내면 다음 세션은 한 가지 수정만 하고 멈추지 않고, 안전한 관련 작업을 여러 slice로 큐잉해 검증 gate를 통과시키며 진행해야 한다.

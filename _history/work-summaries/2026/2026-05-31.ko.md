# 2026-05-31 작업 요약

이 파일은 2026-05-31에 만든 에이전트 플랫폼 운영 구조를 빠르게 보기 위한 요약이다. 상세 맥락은 [_history/2026/2026-05-31.md](../../2026/2026-05-31.md), 계획 과정은 [_history/plans/2026/](../../plans/2026/), 평가는 [_history/evaluations/2026/](../../evaluations/2026/)에서 확인한다.

## 오늘 전체 요약

오늘 작업의 핵심은 "앞으로 여러 프로젝트와 에이전트를 만들 때 AI가 지시를 잊지 않고, 조사-계획-구현-검증-평가-기록-커밋-push를 반복 가능한 운영 체계로 수행하게 만드는 것"이었다.

구체적으로는 개인 에이전트 구축 플랫폼 monorepo의 루트 규칙을 세우고, `agent-platform/`에 Python-first 에이전트 플랫폼의 기본 패키지와 CLI를 만들었다. `_ops/`에는 프롬프트 라우터, 워크플로, 저장소 맵, 조율 보드를 두어 반복 탐색을 줄였다. `_history/`에는 일지, 계획, 평가, 작업 요약, 사용자 요청 요약, 요청-결과 추적, 컨텍스트 아카이브를 나누어 장기 기억 계층을 만들었다.

신뢰성 측면에서는 웹 검색 선행, 출처 수집, 지식 회의론자, hallucination guard, 코딩 조사 에이전트, Perplexity식 research profile을 추가했다. 오픈소스 설치와 설정 파일도 나중에 추적할 수 있도록 설치 감사, source registry, config contract, memory bootstrap manifest를 연결했다.

결과적으로 오늘 저장소는 단순 문서 묶음이 아니라, 앞으로 작업을 시작할 때 읽을 anchor, 작업 중 참조할 workflow, 끝날 때 남길 요약/평가/요청 기록, 그리고 커밋 후 즉시 push하는 운영 루프를 갖춘 초기 플랫폼 상태가 되었다.

## 오늘의 현재 상태

- 저장소는 개인 에이전트 구축 플랫폼 monorepo로 초기 운영 규칙을 갖췄다.
- 공통 운영은 `_ops/`, 지속 규칙은 `_docs/`, 계획/평가/히스토리는 `_history/`, 재사용 조사 내용은 `_research/`, 철학은 `_philosophy/`, 핵심 플랫폼 구현은 `agent-platform/`에서 관리한다.
- 앞으로 의미 있는 작업은 웹 검색, 공개 검색 판단 기록, 메모리 부트스트랩, 프로젝트 경계 확인, 구현, 검증, 필요 시 컨텍스트 아카이브, 사용자 요청 요약, 요청-결과 추적, 작업 요약, 평가, 히스토리, 커밋, push 순서로 닫는다.
- 설치가 실제로 발생한 작업은 추가로 `_history/installations/` 상세 기록과 `_ops/installations/registry.json` 인덱스를 남긴다.

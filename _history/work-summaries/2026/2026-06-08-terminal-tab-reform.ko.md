# 작업 요약: 터미널 탭 개혁

- 터미널 드로어 상단에 readiness strip을 추가해 런타임, 어댑터, 실제 셸, 작업 폴더 상태를 노출했다.
- 시작 패널에 작업 시작, 실제 셸 열기, CLI 연결 점검, 설정 복구 액션을 우선 배치했다.
- 프롬프트 선택과 작업 폴더 세부 조정은 `terminal-advanced-start` 접힘 영역으로 이동했다.
- 사용자 기본 용어를 `PTY` 중심에서 `실제 셸`과 `연결 점검` 중심으로 바꿨다.
- 기존 xterm 기반 검색, 클립보드, 화면 맞춤, 빠른 명령 기능은 유지했다.

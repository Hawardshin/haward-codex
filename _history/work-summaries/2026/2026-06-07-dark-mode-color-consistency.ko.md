# 2026-06-07 다크모드 색상 일관성 작업 요약

## 변경 사항

- 다크 테마 기본 배경, 표면, 선, 텍스트, 상태 색상, 포커스 링 토큰을 더 일관된 팔레트로 정리했다.
- 명시 다크와 시스템 다크의 핵심 토큰이 같은 값을 쓰도록 회귀 테스트를 추가했다.
- 다크모드 기본 텍스트와 포커스 토큰이 순백색으로 튀지 않도록 테스트를 추가했다.
- 앱 루트는 다크인데 `body` 배경이 라이트로 남는 문제를 보정했다.

## 현재 검증

- 색상 토큰 테스트 통과.
- Playwright 데스크톱/모바일 계산 스타일 검증 통과.
- 전체 Workspace Monitor 테스트 통과.
- Workspace Monitor 타입/계약 체크 통과.
- 내부 데스크톱 패키징과 DMG 검증 통과.

## 남은 게이트

- 패키징 후 생성 스냅샷 및 최종 차이 확인.

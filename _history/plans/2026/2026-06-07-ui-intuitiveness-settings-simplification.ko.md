# UI 직관성 단순화 구현 계획

1. 패키징 실패 원인인 Provider credential refresh 타입 문제를 먼저 해소한다.
2. 설정/런타임 패널의 긴 버튼 라벨을 짧은 명령으로 줄이고 긴 의미는 접근성 라벨에 둔다.
3. 계정 설정 안내와 데이터 루트 목록처럼 정보량이 많은 영역을 접거나 제한한다.
4. 첫 실행/init 상태가 사용자가 이해할 수 있게 보이도록 문구와 액션을 정리한다.
5. CSS와 테스트 계약에 버튼 폭, 말줄임, dark/light contrast 유지 조건을 추가한다.
6. 렌더러, 데스크톱, Rust, 내부 패키징까지 검증한다.

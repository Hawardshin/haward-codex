# 계획 기록: 공개 Impress 템플릿 수집과 HTML 참조화

## 작업 모드

- 선택 모드: `standard`
- 이유: 사용자 요청이 실제 파일 수집, 새 도구, HTML 산출물, 프로젝트 문서, 검증, 평가를 포함하는 의미 있는 구현 작업이다.

## 계획

1. 웹 검색으로 무료 PPT/ODF 템플릿 출처와 라이선스 조건을 확인한다.
2. raw storage가 가능한 공개 repository archive를 선택하고 제한 후보는 제외한다.
3. `presentation-agent`에 수집/패키징/HTML 변환 도구를 만든다.
4. 공개 Impress 템플릿을 `.otp`, 썸네일, HTML 참조 페이지, registry, gallery로 생성한다.
5. 요구사항, README, research, source notes, history, timing, evaluation을 연결한다.
6. 단위 테스트, browser smoke test, JSON/workspace/grounding/evaluation 검증을 실행한다.

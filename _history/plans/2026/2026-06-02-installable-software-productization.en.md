# Installable Software Productization Plan

## Work Mode

- `governance`

## Goal

Create a separate project and operating standard for turning the platform into end-user installable software.

## Plan

1. Check official desktop packaging docs through web search.
2. Separate existing `install_mode` from end-user installer packaging.
3. Create the new root project `platform-desktop-app/`.
4. Write the desktop distribution registry, product boundary, packaging strategy, project requirements, and specs.
5. Update shared policy, workflow, prompt, router, index, memory bootstrap, and persistent instructions.
6. Record requirements baseline, change/review notes, history, trace, and evaluation artifacts.
7. Validate, commit, and push.

## Decision

- This turn only establishes structure and productization standards.
- It does not install Tauri/Electron or implement a prototype.
- The first recommendation is a Tauri-first prototype, but the final decision is deferred to the next research/implementation step.

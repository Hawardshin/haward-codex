# 계획 기록: HTML 발표 덱과 스크립트 협업

## 작업 모드

- 선택 모드: `standard`
- 이유: 발표 에이전트 프로젝트에 실제 HTML 산출물 생성 기능, 샘플 artifact, 테스트, 요구사항, 스펙, 히스토리를 추가하는 의미 있는 구현 작업이다.

## 근거

- 웹 검색으로 reveal.js, Slidev, Marp의 발표자 노트와 HTML 발표 생성 흐름을 확인했다.
- 기존 레퍼런스 카탈로그는 출처와 디자인 신호를 제공하지만, 실제 발표 산출물을 만들 렌더러는 아직 없었다.
- 발표 스크립트와 화면 제작을 분리하기 위해 `deck-spec` 계약을 추가하는 것이 유지보수에 맞다.

## 실행 계획

1. `deck-spec` JSON 구조를 만든다.
2. `html_deck.py`를 구현해 16:9 HTML 발표 덱을 렌더링한다.
3. 발표 에이전트 소개용 샘플 deck spec과 HTML artifact를 만든다.
4. 단위 테스트와 정적 검증을 추가한다.
5. 요구사항, 스펙, 연구 노트, 히스토리, 평가를 갱신한다.
6. 커밋하고 푸시한다.

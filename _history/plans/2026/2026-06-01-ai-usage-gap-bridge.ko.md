# 계획 기록: AI 사용 격차와 간극 해소

## 작업 모드

`governance`

## 근거

- 사용자가 AI 활용 방식의 차이와 간극 해소를 플랫폼에 반영하라고 요청했다.
- 외부 근거는 AI task-fit, AI literacy, power user 습관, appropriate reliance, mental model gap을 중심으로 확인했다.
- 기존 저장소에는 검색/조사/검증 구조는 있었지만, 사용자의 AI 활용 수준을 진단하고 좋은 패턴을 자산화하는 전용 profile은 없었다.

## 계획

1. AI 사용 격차를 작업 구조 gap으로 정리한다.
2. `ai-usage-gap-profile.json`으로 진단과 bridge intervention을 설정화한다.
3. 운영 모델, workflow, prompt, router, index, memory bootstrap에 연결한다.
4. 요구사항/스펙/웹 검색 기록/리서치 노트/요약/평가를 남긴다.
5. config contract, memory bootstrap, docs audit, maps, evaluation으로 검증한다.

## 기대 결과

미래 세션은 사용자가 AI를 애매하게 쓰거나 반복적으로 비슷한 실패를 겪을 때, 단순 조언이 아니라 task framing, task-fit, iteration, verification, asset promotion으로 개선하도록 유도한다.

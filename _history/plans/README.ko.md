# 계획 히스토리

이 폴더는 에이전트가 계획을 세운 과정을 저장한다. 작업 결과만 남기면 나중에 왜 그 순서와 판단을 선택했는지 추적하기 어렵기 때문에, 중요한 계획은 실행 전에 별도 파일로 기록한다.

## 파일 위치

```text
_history/plans/YYYY/YYYY-MM-DD-<slug>.ko.md
_history/plans/YYYY/YYYY-MM-DD-<slug>.en.md
```

한국어 문서를 기본으로 작성하고, 중요한 지속 맥락이면 영어 companion 문서도 함께 둔다.

## 기록할 내용

- 초기 요청과 계획 목적
- 검색 질문
- 사용한 검색 채널
- 확인한 내부/외부 출처
- 지식 베이스 검증 결과
- 도출한 인사이트
- 선택한 계획 단계
- 제외하거나 보류한 선택지
- 위험과 불확실성
- 검증 방법
- 계획 변경 이력

## 규칙

- `research-insight-planner-agent`를 쓰는 작업은 `plan_history_targets`를 지정한다.
- 계획이 실행 중 바뀌면 같은 파일에 변경 사유를 남긴다.
- 최종 평가 보고서에서는 관련 계획 히스토리 파일을 링크한다.

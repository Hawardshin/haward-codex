- 요청: 미룬거 계속 구현.
- 처리: 저장된 subagent tool plan의 첫 2개 tool을 bounded fan-out으로 시작하는 `start_subagent_tool_fanout` command를 추가했다.
- 구현: 각 lane은 기존 CLI adapter session으로 시작하고 같은 `pipeline_id`, `lane_id`, `lane_role`, `subagent_manual_merge_gate`를 가진다.

- 경계: default 2 sessions, hard cap 3 sessions. 모든 tool 자동 실행과 자동 merge는 하지 않는다.

# 2026-06-04

## Platform Desktop App

- Upgraded the Native Git Workbench toward GitHub Desktop-style local Git parity: Changes/History/Stash views, include checkboxes, selected/all commit, selected discard, selected/all stash, stash apply/pop/drop, fetch/pull/push, bounded history, and bounded stash payload.
- Added Claw Code as an optional guest CLI adapter reference and runtime target: `claw-code-cli`, setup guidance, task pipe orchestration lane, reference transfer patterns, user-flow/desktop distribution contracts, and readiness coverage.
- Added a runnable existing search-agent surface: `research-insight-planner-agent` now appears in Agents, Desktop quick start, and the command palette, and runs through the bottom terminal with `taskKind=research_insight_agent`.
- Converted the existing search-agent surface from a launch form into a work-chat panel, so users start the agent task in chat while terminal output and task-run records stay attached.
- Added AgentCore Quick Builder behavior to the desktop Agents surface: selected AgentCore-style blueprints now map to Agent Factory proposal forms and can call the native proposal writer directly in the installed app.
- Clarified the AgentCore-style execution boundary: the agent loop and Python process execute in the local desktop runtime, while Lambda/cloud functions are optional tool connectors rather than the execution host.
- Reprioritized the desktop product around two primary capabilities: Agent Core for easy custom agent/subagent creation and CLI Orchestration for continuous guest CLI work. Root Tools and Work Visibility now support those core flows while operator sections are de-emphasized.

## Agent Platform

- Added a framework-neutral manager-as-tools orchestration planner: `plan-agent-orchestration` reads a request JSON, registered agent specs, and the orchestration registry, then emits a manager/subagent tool plan with state, handoff, tool access, human checkpoint, observability, and validation controls.
- Updated `agent-orchestrator-agent`, the orchestration registry, requirements, specs, docs, web-search record, coding-research record, and evaluation targets for the new manager/subagent tool structure.

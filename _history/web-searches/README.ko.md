# 웹 검색 기록

이 폴더는 모든 새 사용자 지시와 재사용 프롬프트 실행 전에 수행한 웹 검색을 추적한다.

## 목적

- "웹 검색을 먼저 했다"는 사실을 채팅 기억이 아니라 파일로 남긴다.
- 검색어, 확인한 출처, 무시한 약한 출처, 계획에 반영한 판단 요약을 추적한다.
- 내부 추론 원문을 노출하지 않고, 사용자와 미래 에이전트가 검증할 수 있는 공개 근거와 결정 요약을 남긴다.

## 경로 규칙

```text
_history/web-searches/YYYY/YYYY-MM-DD-<slug>.ko.md
_history/web-searches/YYYY/YYYY-MM-DD-<slug>.en.md
```

## 필수 내용

- 사용자 지시 요약
- 검색 시각과 검색어
- 확인한 출처와 출처 유형
- 계획에 영향을 준 인사이트
- 무관하거나 약해서 제외한 출처
- 공개 판단 요약
- 관련 작업 요약, 계획, 평가 보고서 링크

## 종료 평가 규칙

의미 있는 작업의 `work-evaluator-agent` 입력에는 `web_search_record_targets`를 포함한다. 웹 검색이 도구/네트워크 문제로 실패했거나 최신 사용자 지시가 검색을 금지한 경우에도 그 사유와 보강한 로컬 검증을 기록한다.

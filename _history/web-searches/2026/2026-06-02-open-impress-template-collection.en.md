# Web Search Record: Open Impress Template Collection And HTML Referencing

## Request Summary

The user asked to collect many free PPT reference files and UI references, download them, and convert them to HTML.

## Queries

- `free PowerPoint templates downloadable pptx license Creative Commons SlidesCarnival PresentationGO Canva Slidesgo terms`
- `open source free pptx templates GitHub license presentation templates PowerPoint`
- `LibreOffice command line convert pptx to html export Impress documentation`
- `pptx to html open source converter GitHub pptx2html`
- `dohliam libreoffice impress templates GitHub license`
- `LibreOffice Impress templates archive github dohliam libreoffice-impress-templates lo-cft CC0`

## Strong Sources Checked

- `dohliam/libreoffice-impress-templates`: public Impress template source archive and collection READMEs.
- GitHub archive: verified and downloaded the source archive.
- Collection READMEs: `lo-cft`, `lo4-design-candidates`, `lo5-design-candidates`, `lo51-templates`, `lo35-templates`, `fedora-slideshow`, `user-contrib/material-simple`.
- LibreTemplates license page: direct downloads exist, but raw storage was excluded because redistribution is restricted.

## Weak Or Excluded Sources

- Canva, Slidesgo, MiriCanvas, and PresentationGO are useful design references, but raw storage and redistribution depend on terms, accounts, or item-level permissions, so they were excluded from bulk raw storage in this task.
- LibreTemplates provides free download links, but the license page restricts redistribution, so raw files were excluded.

## Plan Impact

- Instead of bulk-downloading PPTX files, the task selected 119 license-cleared public LibreOffice Impress `.otp` templates.
- HTML conversion was scoped to thumbnail/provenance/license/extracted-text reference cards, not high-fidelity PPT rendering.
- LibreOffice/`soffice` is unavailable locally, so renderer installation was left as a future improvement.

## Uncertainty

- `lo35-templates` is described by the README as appearing to be LGPLv3, so the registry records it as `open_source` but item-level review is still needed before public redistribution or commercial use.
- Converting `.otp` templates into actual PPTX requires LibreOffice or another verified renderer.

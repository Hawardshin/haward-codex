# 웹 검색 기록: Do-All Completion Standard

## 검색 시각

2026-06-06

## 쿼리

- `software engineering definition of done acceptance criteria complete all requested scope best practices`
- `task completion software project management definition of done acceptance criteria no partial completion`
- `large task execution complete all acceptance criteria incremental delivery definition of done`

## 확인한 내용

- Definition of Done는 작업이 완료됐다고 말하기 전에 충족해야 하는 공통 완료 기준으로 쓰인다.
- Acceptance criteria는 특정 요청이나 user story가 충족해야 하는 조건이며, 완료 판단에는 acceptance criteria와 DoD가 함께 쓰인다.
- “all acceptance criteria met” 같은 기준은 partial completion을 완료로 오인하지 않게 하는 장치다.

## 계획 영향

사용자 지시 “다하기”를 durable completion standard로 반영했다. 앞으로 “다하기/전부/모두/do all”류 요청은 요구사항, 구현, 생성 산출물, 검증, 빌드/패키징, 기록, commit, push까지 적용 가능한 전체 완료 기준으로 확장한다.

- `Nielsen Norman Group visual hierarchy UI design first screen task focus`

## 확인한 출처

- Material Design layout principles: typography, grid, space, scale, color로 hierarchy와 focus를 만든다는 기준을 확인했다.
- Material Design cards: 카드 내부 요소는 hierarchy를 명확히 드러내야 하며 primary action은 카드의 주요 행동이어야 한다는 기준을 확인했다.
- Apple Human Interface Guidelines: controls와 interface elements가 콘텐츠의 시각 계층을 명확히 해야 한다는 기준을 확인했다.

## 계획 영향

- Overview에서 운영 strip, 문서 필터, 상태 지표보다 목표 선택 카드를 먼저 보이게 했다.
- 상태 숫자는 목표 선택 이후의 보조 요약으로 낮췄다.
- desktop/mobile smoke에서 목표 카드의 화면 상단 위치와 보조 strip 제거 여부를 수치로 확인했다.

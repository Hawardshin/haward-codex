# 2026-06-05 Industrial Control Affordance 웹 검색

## 질의

- `Apple Human Interface Guidelines buttons controls official`
- `Material Design 3 buttons interaction states official`
- `IBM Carbon Design System buttons usage official`
- `Nielsen Norman Group Fitts Law touch targets usability`

## 확인한 출처

- Apple Human Interface Guidelines: 명확한 hierarchy, platform-consistent controls, control feedback 원칙을 확인했다.
- Material Design button guidance: 버튼의 action, state, hierarchy가 구분되어야 한다는 방향을 확인했다.
- Carbon Design System button guidance: 제품 UI에서 버튼 purpose, kind, state를 일관되게 다루는 기준을 확인했다.
- Fitts's Law 관련 UX 자료: 조작 대상 크기와 이동 거리가 사용 속도와 정확도에 영향을 준다는 근거를 확인했다.

## 계획 영향

- 작업 목표 버튼을 단순 카드형 버튼이 아니라 번호, 아이콘, 설명, badge, action cue가 분리된 조작 패널로 바꾼다.
- desktop dock 버튼은 더 큰 hit target과 tactile hover/focus/active 상태를 가진다.
- 모바일에서는 action cue와 텍스트 우선으로 재배치한다.

## 불확실성

- 이번 변경은 Overview 작업 dock에 한정한다.
- 실제 사용자의 손 위치/시선 이동 계측은 수행하지 않았다.

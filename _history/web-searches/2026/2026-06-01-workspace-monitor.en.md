# Web Search Record: Workspace Monitor

## Request Summary

- Create a new Next.js monitoring site project that visualizes repository history, Markdown documents, agent/project status, and can be deployed to Vercel.

- `Next.js App Router official docs static export Vercel deployment`

## Plan Impact

- Use Next.js App Router and static export for easy Vercel/public deployment.
- Generate a snapshot before build so the static UI reads JSON instead of reading files at runtime.
- Convert Markdown to escaped HTML previews instead of executing full MDX, reducing raw HTML exposure risk.
- Use lucide-react only for UI tab/button icons.

## Uncertainty

- Vercel monorepo parent-directory access can change. The snapshot is committed, and `prebuild` collection is best-effort.
- Before public release, the user must review which source documents are included in the snapshot.

## Public Decision Summary

- The app should be a static snapshot dashboard rather than a server-runtime repository reader, which keeps Vercel deployment and later public release simpler.

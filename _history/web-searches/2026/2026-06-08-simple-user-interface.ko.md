# 웹 검색 기록: 기본 사용자 인터페이스 단순화

## 검색어

- `progressive disclosure UX complex software beginner interface advanced settings hidden by default`
- `desktop app UX simplify complex workflow primary task surface progressive disclosure settings`
- `agent workflow UI human in the loop simple interface advanced automation hidden`
- `Nielsen Norman progressive disclosure user interface complexity`

## 확인한 출처

- Apple Developer Documentation, Disclosure controls: https://developer.apple.com/design/human-interface-guidelines/disclosure-controls
- Microsoft Learn, Progressive Disclosure Controls: https://learn.microsoft.com/en-us/windows/win32/uxguide/ctrl-progressive-disclosure-controls
- IBM Docs, Progressive Disclosure: https://www.ibm.com/docs/en/technical-content?topic=practices-progressive-disclosure
- UXPin, Progressive Disclosure overview: https://www.uxpin.com/studio/blog/what-is-progressive-disclosure/

## 반영한 판단

- 핵심 작업은 기본 표면에 두고, 고급 기능과 세부 설정은 명시적 선택 뒤로 보낸다.
- 사용자 기본 화면은 설명 페이지가 아니라 실제 작업 입력과 실행 액션이어야 한다.
- 고급 기능 숨김은 보안 경계가 아니므로 view mode 정책에 security note를 유지한다.

## 제외한 약한 근거

- Reddit와 개인 블로그는 UX 발견 신호로만 보고 구현 근거로 쓰지 않았다.
- 오래된 Windows 7 가이드는 최신 시각 스타일 근거가 아니라 progressive disclosure 원칙 확인용으로만 사용했다.

## 남은 불확실성

- 실제 첫 실행 성공률은 패키지된 데스크톱 앱에서 사용자 테스트와 native runtime smoke가 필요하다.

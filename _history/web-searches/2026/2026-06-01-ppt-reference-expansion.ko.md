## 계획에 반영한 인사이트

- 미리캔버스/Canva/Slidesgo 같은 템플릿 갤러리는 디자인 참고 가치가 높지만 원본 저장은 item별 약관 확인 전 금지한다.
- Genspark식 방식은 “주제 입력 → 조사/구조화 → 디자인 단계 → 템플릿 적용 → PPTX export/import” 흐름으로 참고한다. 단, 품질은 자동 생성보다 템플릿 일관성, design token, layout archetype 고정이 좌우한다.
- 사용자가 직접 제공하는 PPT는 저작권이 불명확한 온라인 원본보다 안전하게 reference profile을 만들 수 있다. 그래도 저장/커밋은 사용 권한을 확인한 뒤 진행하고, 기본은 로컬 전용 raw 폴더에 둔다.
- 좋은 템플릿은 개별 슬라이드가 예쁜 것보다 같은 색/타이포/그리드/컴포넌트/섹션 리듬을 유지하는 것이 중요하다.

## 약하게 취급한 출처

- Reddit/커뮤니티 글은 Genspark나 다른 AI slide tool의 실사용 불만, 품질 이슈, 프롬프트 팁 발견용으로만 참고한다.
- 템플릿 다운로드 mirror, 비공식 공유 사이트, 출처가 불분명한 PPT 모음은 사용하지 않는다.

## 공개 판단 요약

이번 변경은 원본 PPT를 대량 다운로드하지 않는다. 대신 presentation-agent의 catalog에 새 PPT/AI slide/source 후보를 추가하고, 사용자가 가져온 PPT를 안전하게 분석해 디자인 토큰과 레이아웃 archetype으로 바꾸는 workflow를 추가한다.

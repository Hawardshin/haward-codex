# Agent First-Run Guide Web Search

- 날짜: 2026-06-07
- 요청 요약: 사용자가 에이전트 설정과 실제 첫 실행 순서를 이해하지 못하는 문제를 UI에서 해결한다.
- 검색어:
  - `official OpenAI Codex CLI AGENTS.md setup agents guide`
  - `Nielsen Norman Group onboarding setup wizard UX visibility system status`
- 확인한 출처:
  - OpenAI Developers, Codex CLI docs: https://developers.openai.com/codex/cli
  - OpenAI Help Center, Using Codex with ChatGPT plan: https://help.openai.com/en/articles/11369540-codex-in-chatgpt
  - Nielsen Norman Group heuristic summary: https://media.nngroup.com/media/articles/attachments/Heuristic_Summary1_A4_compressed.pdf
- 계획 반영:
  - Codex/agent 설정은 `AGENTS.md`, CLI 실행 경로, 모델 계정 또는 로컬 모델, 실제 task run 확인이 한 흐름으로 보여야 한다.
  - 사용자가 지금 해야 할 단계와 이미 준비된 단계를 같은 카드에서 확인할 수 있게 Quick Start 상단에 첫 실행 안내를 둔다.
  - 긴 설명 대신 기존 설정/실행/터미널/실행 기록 액션으로 바로 이동하는 버튼을 제공한다.
- 무시한 약한 출처:
  - 비공식 블로그와 커뮤니티 글은 제품 문구 결정에는 참고하지 않았다.
- 공개 판단 요약:
  - 이 작업은 외부 최신 사실보다 로컬 제품 흐름 개선이 핵심이다. 외부 출처는 단계 가시성 및 Codex 설정 개념을 확인하는 보조 근거로만 사용했다.

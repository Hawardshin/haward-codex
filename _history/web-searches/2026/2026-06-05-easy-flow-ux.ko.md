# 2026-06-05 Easy Flow UX 웹 검색

## 질의

- `Nielsen Norman Group task flow progressive disclosure UX reduce cognitive load`
- `Material Design navigation task flows progressive disclosure guidelines`
- `Apple Human Interface Guidelines navigation progressive disclosure user flows`

## 확인한 출처

- Nielsen Norman Group progressive disclosure 관련 자료: 복잡한 기능은 단계적으로 노출해 인지 부하와 오류를 줄이는 방향을 확인했다.
- Material Design Navigation: task는 목표 달성을 위한 활동 sequence이며, 단순한 사용자 요구에는 lightweight structure를 사용하라는 기준을 확인했다.
- Apple HIG Disclosure Controls: 고급 선택지를 필요한 시점에 확장하는 disclosure control 기준을 확인했다.

## 계획 영향

- 기존 handoff strip에 목표별 3단계 이하 작업 흐름을 붙여 사용자가 대상 화면에서 다음 순서를 즉시 이해하게 했다.
- 모바일에서는 단계 레일을 한 열로 쌓아 작은 화면에서도 줄바꿈과 overflow 부담을 줄였다.

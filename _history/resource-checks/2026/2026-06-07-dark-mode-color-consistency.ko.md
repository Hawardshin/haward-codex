# 2026-06-07 다크모드 색상 일관성 리소스 점검

## 리소스 사용

- 로컬 Next 개발 서버를 `127.0.0.1:3217`에서 실행해 렌더링을 확인했다.
- 인앱 브라우저로 시스템 다크 계산 스타일을 확인했다.
- Playwright로 명시 다크 계산 스타일을 데스크톱과 모바일 뷰포트에서 확인했다.

## 정리

- 검증 후 `127.0.0.1:3217` 포트의 Next 프로세스를 종료했다.
- 남은 장기 실행 서버나 브라우저 자동화 프로세스는 없다.

## 위험

- `body:has(...)` 기반 보정은 현대 Chromium/WKWebView/Safari 계열에서 지원되는 선택자를 사용한다. Tauri macOS WebView의 지원 범위와 맞지만, 향후 오래된 런타임 지원이 필요하면 루트 클래스 기반 전역 테마 주입으로 바꿀 수 있다.

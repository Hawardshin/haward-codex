# 요청-결과 추적: 공개 Impress 템플릿 수집과 HTML 참조화

## 요청

사용자는 무료 PPT 레퍼런스 파일과 UI를 많이 모아 다운로드하고 HTML로 전환해 달라고 요청했다.

## 결과

- `dohliam/libreoffice-impress-templates` archive에서 라이선스가 확인된 7개 collection을 수집했다.
- 119개 공개 LibreOffice Impress `.otp` 파일을 생성했다.
- 119개 썸네일과 119개 HTML 참조 페이지를 생성했다.
- 전체 갤러리와 JSON registry를 생성했다.
- 제한 약관이 있는 무료 템플릿 후보는 raw 저장에서 제외했다.

# 컨텍스트 아카이브

이 폴더는 대화 컨텍스트가 길어졌을 때 다음 세션이나 다음 작업자가 저장소 문서만 보고 이어갈 수 있도록 만든 압축 재개 패킷을 보관한다.

## 목적

- 긴 채팅을 작업 상태의 유일한 저장소로 두지 않는다.
- 안정된 결정, 요구사항, 현재 상태, 남은 작업, 검증 결과를 짧게 압축한다.
- 세부 내용은 원문을 복사하지 않고 관련 문서, 히스토리, 평가 보고서, 커밋, 검색 기록으로 되돌아가게 한다.
- 내부 추론 원문이나 임시 로그는 저장하지 않는다.

## 경로 규칙

```text
_history/context-archives/YYYY/YYYY-MM-DD-<slug>.ko.md
_history/context-archives/YYYY/YYYY-MM-DD-<slug>.en.md
```

## 언제 만든다

- 대화가 길어져서 다음 응답에서 중요한 맥락을 잃을 위험이 있다고 판단할 때
- 여러 작업이 누적되어 현재 상태를 한 파일로 재개해야 할 때
- 프로젝트 방향, 작업 순서, 남은 작업이 채팅에만 남아 있을 때
- 컨텍스트 압축 전환이나 세션 종료 전에 미래 작업자가 이어받아야 할 때

## 필수 내용

- 현재 작업 목표
- 최근 완료한 결정과 변경
- 반드시 읽을 문서와 파일
- 현재 검증 상태
- 남은 작업과 다음 행동
- 프로젝트별 소유 경계
- 관련 웹 검색 기록, 계획 기록, 평가 보고서, 커밋
- 저장하지 않은 내용과 이유

## 사용 순서

1. 최신 `_history/work-summaries/` 요약을 먼저 읽는다.
2. 해당 작업의 context archive packet을 읽는다.
3. packet의 `Must Read` 파일만 우선 열어본다.
4. 세부 근거가 필요할 때만 연결된 히스토리, 평가, 리서치, 커밋을 추적한다.
5. 오래된 packet을 사용할 때는 `knowledge-skeptic-agent`로 현재성, 충돌, 누락을 확인한다.

## 평가 규칙

컨텍스트 아카이빙이 실제로 발생한 작업은 `work-evaluator-agent` 입력에 `context_archiving_occurred=true`와 `context_archive_targets`를 포함한다.

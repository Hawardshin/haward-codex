# Work Mode Selection

작성일: 2026-06-06

## 선택 모드

`standard`

## 이유

- 사용자 요청은 단순 질문이 아니라 desktop app 저장소 구조와 성능 병목 판단에 영향을 준다.
- 코드 구현보다 요구사항, 아키텍처 결정, 마이그레이션 계획, 검증 기록이 필요한 작업이다.
- 실제 DB 의존성 설치는 이번 범위에서 제외하므로 `governance`나 full implementation mode까지는 필요하지 않다.

## 범위

- 웹 검색 우선 수행
- 현재 파일 기반 저장 경로 조사
- 하이브리드 저장소 결정 기록
- 검증 및 패키징
